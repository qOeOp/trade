# R1 research archive

This directory preserves experiment records, source checks, result artifacts and historical analysis scripts from the local Nautilus fork. It is evidence for ongoing research, not the supported replay implementation. Some Python scripts import the removed `vibe_trading` package and cannot be run on the minimal architecture as written.

Use `strategies/r1/` for current Strategy source and native shared-account replay. When a historical diagnostic is needed, port its question to the published `nautilus_trader` API and record the new result without overwriting the prior experiment. For a new round, follow [`research.records`](../records/README.md): find/show/compare the existing lineage, commit an attempt before the new result, and verify/register a native run artifact. Preserve `RD_EXPERIMENTS.md`, `SOURCE_CASES.md`, result identities and provenance; use `RECORD_INDEX.md` for cross-reference. H25a/H26a/H27a structured entries are retrospective transcriptions, and their old `/tmp` CSVs are not sealed. Keep strategy hypotheses, outcomes, failures and next experiments in the corresponding attempt and H/D/S record. Put only repeated or major shared research-workbench capability gaps in `docs/plans/r1-native-rd-findings.zh.md`, with affected attempts, blocked Agent task, evidence, iteration cost, workaround and minimum common capability. The historical F01-F97 body remains for traceability, not as a module backlog.
