# Ronnie R-1 experiment ledger

Research goal: `01a11518-fb33-7853-a31c-b8c43df5be60`. The exit targets are a reproducible, fee- and funding-inclusive **single-account** annualized return above 20%, a closed-trade win rate near 60%, and then the highest defensible Sharpe ratio, with drawdown reported. No exchange trading is authorized.

Operational comparison convention: annualize the native final-equity ratio over actual UTC calendar days using 365 days/year; one closed native position is one trade even with partial exits; a win has positive native position `realized_pnl`, which includes fill commissions in settlement currency. Funding is charged to the native account and reflected in equity, but is not allocated to this position-level win flag. For mechanism screening, interpret "near 60%" as 55-65% inclusive, declared before selecting any new strategy variant. Report the native daily-return Sharpe using both 252 and 365 annualization; prefer 365 for this continuous crypto market. This convention does not turn development data into independent evidence.

Product and process findings for later blueprint reconciliation are in `docs/plans/r1-native-rd-findings.zh.md`.

This file records source observations, diagnostic hypotheses, exact data/result locators, outcomes, and next decisions. The 2025-10-07 to 2026-10-07 Binance futures sample and the 2026-09 to 2026-10 sample have already been inspected. Further results from them are development evidence, even if the code was registered before a particular rerun. All attempted variants and reads remain visible here; overlapping slices are not independent holdouts. Use predeclared mechanism changes, paired native replay, multiple-testing-aware uncertainty and later forward evidence to address this exposure. Lack of a fresh historical holdout does not stop the research.

**Question and read:** Before investing in a native partial-exit variant to raise the win rate, measure the opportunity in the clean D04 account without simulating new orders. `analyze_exits.py` joins each native closed position's entry fill to its linked native stop trigger, then scans the reused LAST five-minute catalog between native entry and exit timestamps. **Observed path:** 1,625 closed native positions include 595 positive, 1,027 closed by stop-market fills, 590 by limit target fills and eight by market fills.
