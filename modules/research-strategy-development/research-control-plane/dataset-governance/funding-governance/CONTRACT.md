# research/funding-governance

## Type

atomic module

## Owns

- Funding carry data readiness checks.
- Funding event coverage governance before funding-carry research trials.
- Stable script response envelope for funding governance output.

## Inputs

- Panel datasets with OHLCV manifests.
- Optional indicator reports with exact funding events.

## Outputs

- Funding carry governance report.

## Boundaries

- Does not run R&D search, replay, review, promotion, or exchange calls.
- Does not write files, catalog, or `trade.db`.
- Uses `replay-execution-plane/benchmark` for shared funding coverage semantics.
