# Research Control Plane Contracts

Owns the stable cross-plane identity and Draft Strategy authorization contracts.

## Responsibilities

- Define `Planner Control Plane Context Snapshot v1` as the only context identity accepted by the Planner role. The snapshot canonically orders active L3 Universe nodes、their exact Data Surface requirement links、coverage、Data Surfaces、active/experimental capabilities and bounded lesson refs, then binds them with `context_hash`. It is a read fact, not a Proposal、Contract、queue write or trial authorization.
- Define immutable `Replay L2 Experiment Attachment Authority v1`. It binds one authoritative reserved Trial、exact Request、full canonical OHLCV Dataset Manifest、one owner-pinned compacted epoch source and one validated bounded batch to a half-open frame range. It keeps the attachment separate from the OHLCV manifest, persists no raw depth rows, grants no Runner/Fill/queue/economic authority, and fixes external completeness to `not_verified`.
- Define immutable `Bar-linked Aggregate Trade Path Authority v1` as a Request-specific successor to Aggregate Trade Evidence Admission、Cross-source Ordering Admission and Replay-owned Kline↔Aggregate Trade Bar Link. It authorizes only one initial Stop-market Request/bar to use ordered aggregate-trade prices for post-entry protection ordering, strictly after the triggering trade. It binds exact entry/stop/target prices and leaves Runner activation forbidden、Fill quantity/cost authority none、external completeness unverified and all queue/slippage/impact/insurance/ADL/default-cutover claims closed.
- Define the immutable identity binding shared by Trial, Replay, Forward, and Draft Strategy registration, including Experiment Contract v3 `replay_execution_input` and Trial Reservation v9 bindings for Replay risk/spec/status schedules, instrument-status provenance, the Control Plane-certified status-provider capability, supplemental revision stream, Contract-derived Requirement Set and nullable liquidity-capacity-attestation hash.
- Define self-hashed Portfolio Allocation、Reallocation and Cycle Sequence Reservations. Allocation freezes one initial candidate budget；Reallocation v1 remains a cycle-2 compatibility authority bound to one predecessor Result/Manifest。Cycle Sequence v1 is the multi-cycle authority：it freezes one contiguous 1–8 cycle schedule, exact Allocation/Risk Plan hashes, current Trial/Lane identities, priority, caps and strictly increasing earliest times. Only cycle 1 carries frozen initial cash；successor opening cash is derived by Replay from predecessor `ending_available_cash`. Runtime append/search expansion、cycle-number authority schemas and Result mutation are forbidden.
- Define a separate self-hashed P27 Two-Fixed-Partial Cycle Sequence Reservation. It freezes 1–8 exact child P27 Reservation hashes、current Trial/Request identities and strictly increasing cycle times；successor admission requires the predecessor committed full-flat Trial Balance, and runtime append、third partial、mutation or search expansion is forbidden.
- Define the self-hashed Instrument Status Provider Certification v1 snapshot. It binds one Market Data provider build/normalization capability to a certifier, policy and half-open validity window; Dataset producers and Replay workers cannot mint this authority.
- Define the self-hashed Provider Certification Termination v1 fact. It is append-only, non-retroactive and either revokes one certification or supersedes it with a separately registered successor; it changes only future Control Plane admission and is not Replay input.
- Define a separate self-hashed Aggregate Trade Provider Certification v1. It binds the exact provider capability/build/policy, Archive v1 input and Replay Event/Attestation output schemas while fixing external completeness to `not_verified`; it never reuses the incompatible Instrument Status certification.
- Define Aggregate Trade Provider Certification Termination v1 and Reservation-bound Evidence Admission v1. Admission embeds the certification snapshot and archive/receipt/audit/evidence/attestation hashes, but its only scope is `pre_integration_exact_price_path_only`; it is not Trial Reservation v9, Request v30, Runner or Fill authority.
- Define Cross-source Ordering Admission v1. It binds one Replay-owned Ordering Attestation to the same reserved Trial、Reservation、Aggregate Trade Evidence Admission、Dataset/status authority and exact four-source collection hashes. Scope is `pre_integration_cross_source_ordering_only` with `economic_authority=none`; Reservation v9 and production wire remain unchanged.
- Define Decision Observation Bundle Admission v1. It binds one validated Request v30、Reservation v9、registered Cross-source Ordering Admission、Wire v2、frozen Decision Schedule and portable Observation Bundle to the authoritative reserved Trial. The receipt only grants `non_economic_decision_observation_audit`; it certifies Wire identity plus Schedule binding, explicitly leaves Projection derivation `not_certified`, and grants no Harness、Runner、Decision、Signal、Order or economic authority.
- Define Decision Observation Bundle Derivation Admission v1 as a new receipt rather than mutating Bundle Admission v1. It binds the prior Admission and Replay-owned Derivation Attestation identities, validates every boundary against the admitted Bundle, and grants only non-economic derivation audit. Control Plane validates schema/hash plus admitted-Bundle binding; it does not replay Replay-owned parents or grant Harness、Runner、Decision、Signal、Order or economic authority.
- Define separate self-hashed Reservation Cancellation v1 and Attempt Cancellation v1 receipts. The former fences future claims at its effective time; the latter targets one exact active lease generation. Neither receipt is Replay economic input or mutable Trial state.
- Define self-hashed Attempt Cancellation Observation v1 as a worker submission bound to one cancellation hash、lease generation and cancelled Run Outcome v35. It is evidence of cooperative observation, not a second cancellation authority or a stopping-latency claim.
- Define self-hashed Current Attempt Lease Observation Receipt v1. It is a positive Control Plane fact for one exact active Lease generation at caller-supplied `observed_at`, binds the complete Lease hash, and explicitly distinguishes single-transaction read consistency from external clock attestation or dispatch authority.
- Define self-hashed Lease Observation Registry Read Receipt v1. It binds one immutable registered observation row, its `registered_at`, one same-transaction current active Attempt/Lease read and caller-supplied `read_at`. It proves Control Plane registry-read provenance only；it is not an external clock attestation or execution admission.
- Define self-hashed Dispatch Clock Attestation v1. It binds authority-internal wall/monotonic samples bracketing one Registry Read Receipt, forbids caller timestamp input and preserves the exact Attempt/worker/generation/Lease hash. This proves local clock-source independence only, not signed TSA/NTP/remote trusted time or execution admission.
- Define capsule-bound Spawn Boundary Revalidation Request/Receipt v1. Replay supplies only immutable capsule/authority hashes and expected Attempt fencing identity；Control Plane internally brackets one direct current-Attempt transaction with its own wall/monotonic clock and returns the exact active Lease. The Receipt grants one immediate spawn candidate transition, not process-start evidence、dispatch、Harness or economic authority, and cannot prove absence of cancellation after its completed read.
- Define the only authorization accepted by Strategy Registry: an `accept_for_draft` Reviewer Decision bound to one completed Trial and primary Result.
- Define the registered Draft Strategy binding consumed by Forward Evidence Plane.
- Reject incomplete or mutable-looking boundary objects before owner commands run.

## Boundaries

- Does not persist facts, execute Replay, render strategy markdown, or decide promotion.
- Does not expose Control Plane database internals.
