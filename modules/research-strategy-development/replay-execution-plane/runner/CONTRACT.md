# Replay Trial Runner

Owns Trial-scoped Replay orchestration, Attempt authority validation, attempt-local idempotency, cooperative cancellation, resumable checkpoint handoff, typed failure, and durable Result Artifact commit.

Artifact Manifest v23 is the success commit marker. Runner requires Control Plane-issued Trial Reservation Snapshot v5 and Replay Attempt Lease v1, verifies request/reservation/lease hashes, risk/spec schedule, supplemental-facts and supplemental-requirement-set hashes, `issued_at <= claimed_at < expires_at`, and the current lease window before cancellation, attempt-local idempotency lookup, engine work, or publication. Reservation expiry closes new Attempt admission but does not terminate a previously admitted Attempt; lease expiry/generation alone fences execution. After a committed-idempotency miss, Adapter builds Decision Input Snapshot v1. `signal_time_complete` requires Request `harness_hash` to equal an immutable Source Bundle v1 hash; Runner accepts only Registry Capability v1 with fixed Registry/Loader Policy, resolves one reviewed static entrypoint, invokes it once, rejects a non-identical derived Order, and creates Harness Capability/Receipt v2 before Engine. Unknown/tampered bundle or registry/loader drift is rejected before market execution. `mode=none` has null Bundle/Receipt and does not claim recomputation; committed-idempotency reads neither resolve nor invoke Harness. This port certifies source-set identity and registered resolution, not source-to-build attestation, dependency/runtime bytes or process isolation. Runner reads/writes only through the Attempt-scoped Artifact Store port; `artifact_root` is a compatibility constructor for the certified local adapter, not a second storage path. Each local Attempt namespace uses file `fsync`, same-directory hard-link create-if-absent CAS, and directory `fsync`; same-path/same-content retry is idempotent, different content collides. Manifest persists the storage-policy version and binds producer Attempt/lease, complete supplemental stream, nullable Decision Bundle, Decision Snapshot, nullable Harness Receipt, exact required role set, every member SHA-256, last EventKey, and terminal completeness hash. Run Outcome v18 retains typed authority/storage/Harness rejection; unsupported authority/backends fail before engine execution or publication.

Step Engine may emit Engine Checkpoint v6 only after a complete source-event boundary. With a certified Artifact Store, Runner durably publishes immutable attempt/lease-generation/source-offset/hash-versioned payload and Diagnostic Checkpoint Commit v2, then passes the committed descriptor to the external control callback. The orchestrator may synchronously register Checkpoint Receipt v2 before returning continue/cancel; Runner never writes Control Plane state. Receipt v2 and both commit kinds bind the storage-policy version; legacy no-`fsync` receipts cannot authorize current resume. Prior registered files remain valid if the process crashes while producing or registering a later boundary. Cooperative cancel returns no Result/Artifact and carries the latest commit; another process may resume only with Control Plane-issued Resume Authorization Snapshot v1 based on the source Attempt's latest receipt. Resume revalidates authorization, source producer, target lease, Attempt namespace confinement, hashes, storage policy and canonical source prefix. Successful execution removes only its own versioned diagnostics; prior terminal Attempts remain isolated. Directory/object listing is never recovery authority. Capability v1 defines the remote target as conditional `If-None-Match: *`, full-content SHA-256 collision identity, strong read-after-write, Manifest-last, and abort/expiry of uncommitted uploads; no remote adapter is certified yet.

If the simulated full close leaves negative isolated collateral, Runner returns typed `liquidation-deficit-unsupported` with the breached snapshot, trigger observation, and `remaining_collateral`; it publishes neither Result nor Artifact and never invents insurance-fund, bankruptcy-price, or ADL facts.

An open position reaching manifest-bound delisting returns `instrument-delisted-with-open-position`, carries the phase-`00` terminal EventKey, is non-retryable, and commits no partial Result. A settlement price requires a separately frozen data contract; Runner does not synthesize one.
