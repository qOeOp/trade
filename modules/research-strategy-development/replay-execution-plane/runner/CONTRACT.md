# Replay Trial Runner

Owns Trial-scoped Replay orchestration, Attempt authority validation, attempt-local idempotency, cooperative cancellation, resumable checkpoint handoff, typed failure, and durable Result Artifact commit.

Artifact Manifest v18 is the success commit marker. Runner requires Control Plane-issued Trial Reservation Snapshot v1 and Replay Attempt Lease v1, verifies request/reservation/lease hashes and lease time window before cancellation, attempt-local idempotency lookup, engine work, or publication. Each Attempt writes an isolated directory; every member and the final Manifest use local file `fsync` followed by same-directory hard-link create-if-absent CAS and directory `fsync`. A same-path/same-content retry is idempotent; different content is a collision and cannot overwrite published evidence. Manifest persists the storage-policy version and binds producer Attempt/lease, the exact required role set, every member SHA-256, last EventKey, and a terminal completeness hash. Run Outcome v11 exposes `rd-replay-local-fsync-link-cas-v1` through its commit, the latest accepted Attempt generation, accepted Resume Authorization hash when present, and either the authoritative manifest commit or a diagnostic checkpoint commit so Control Plane can fence finalization.

Step Engine may emit Engine Checkpoint v1 only after a complete source-event boundary. With `artifact_root`, Runner durably publishes immutable attempt/lease-generation/source-offset/hash-versioned payload and Diagnostic Checkpoint Commit v2 files, then passes the committed descriptor to the external control callback. The orchestrator may synchronously register Checkpoint Receipt v2 before returning continue/cancel; Runner never writes Control Plane state. Receipt v2 and both commit kinds bind the storage-policy version; legacy no-`fsync` receipts cannot authorize current resume. Prior registered files remain valid if the process crashes while producing or registering a later boundary. Cooperative cancel returns no Result/Artifact and carries the latest commit; another process may resume only with Control Plane-issued Resume Authorization Snapshot v1 based on the source Attempt's latest receipt. Resume revalidates authorization, source producer, target lease, path confinement, commit/payload hashes, storage policy and canonical source prefix. Successful execution removes only its own versioned diagnostics with directory `fsync`; prior terminal Attempts remain isolated. Directory scanning is not authority. This policy is local-filesystem-only; object-store conditional put/CAS, remote garbage collection and cross-filesystem publication remain pending.

If the simulated full close leaves negative isolated collateral, Runner returns typed `liquidation-deficit-unsupported` with the breached snapshot, trigger observation, and `remaining_collateral`; it publishes neither Result nor Artifact and never invents insurance-fund, bankruptcy-price, or ADL facts.

An open position reaching manifest-bound delisting returns `instrument-delisted-with-open-position`, carries the phase-`00` terminal EventKey, is non-retryable, and commits no partial Result. A settlement price requires a separately frozen data contract; Runner does not synthesize one.
