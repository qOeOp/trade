# Replay Trial Runner

Owns Trial-scoped Replay orchestration, Attempt authority validation, attempt-local idempotency, cooperative cancellation, resumable checkpoint handoff, typed failure, and durable Result Artifact commit.

Artifact Manifest v38 is the success commit marker. Runner 对 Result v36/OHLCV Evidence v3 首次发布与幂等读取执行两层校验：先绑定 SourceEvent、protection OrderEvent 与 terminal Fill identity，再从 Request、Dataset accounting 和 entry Fill 重算 path economics，并要求 canonical price/fee 等于实际 terminal Fill。Fingerprint 分别绑定完整 evidence collection、instrument-status schedule、provenance 与 provider certification；Run Outcome v35 只有 completed 可以携带 Result/Artifact。Checkpoint 保持 v17，因为这些 authority 已由 Request/Reservation hash 冻结，economic envelope 是恢复后重建的派生证据。

Step Engine may emit Checkpoint v17 only after a complete source-event boundary. Runner durably publishes the Attempt/lease-generation/source-offset-bound payload and Diagnostic Checkpoint Commit v2, then hands the descriptor to external Control Plane coordination; Runner never writes Control Plane state. Reservation Cancellation v1 is enforced before a new claim. Active Attempt Cancellation v1 必须随 `cancel` 回调绑定原始 receipt；Runner 拒绝 generation/binding 漂移，以 Run Outcome v35 返回 self-hashed Observation v1，且不发布 Result/Artifact。取消已先使 Attempt terminal，故边界产生的本地 diagnostic checkpoint 不自动获得 Receipt/Resume authority。Resume 仍须 Control Plane Resume Authorization v1 并重验 authority、storage、Timeline、status/source prefix、OrderEvent last-state、partial Fill 与 rebuilt protection generation；clean/resume Result hash 必须一致。SQLite reference directive/observation 已认证，remote transport 与 stop-latency SLA 尚未认证。

If the simulated full close leaves negative isolated collateral, Runner returns typed `liquidation-deficit-unsupported` with the breached snapshot, trigger observation, and `remaining_collateral`; it publishes neither Result nor Artifact and never invents insurance-fund, bankruptcy-price, or ADL facts.

An open position reaching manifest-bound delisting returns `instrument-delisted-with-open-position`, carries the phase-`00` terminal EventKey, is non-retryable, and commits no partial Result. A settlement price requires a separately frozen data contract; Runner does not synthesize one.

`dataset-grid-gap-in-execution-window` is a non-retryable `data_integrity` failure. Its self-validating evidence distinguishes `missing_earliest_executable_bar` from `open_position_grid_gap` and binds exact missing bounds/count. Runner publishes neither Result nor Artifact, whether the failure is raised by admission or source reduction. Retry is meaningful only after Control Plane freezes a different Dataset Manifest/Data Hash; it cannot reinterpret the same immutable input.

`maintenance-margin-breach-while-halted` is a non-retryable `deterministic_engine` failure. Runner preserves the exact Funding/Mark EventKey、margin snapshot 与 non-authoritative maintenance-breach observation，but publishes no Result/Artifact and never converts the frozen mark into an executable liquidation Fill. Resume uses Checkpoint v17 status-source prefix, so it cannot skip the halt or replay Funding.
