# Replay Trial Runner

Owns Trial-scoped Replay orchestration, Attempt authority validation, attempt-local idempotency, cooperative cancellation, resumable checkpoint handoff, typed failure, and durable Result Artifact commit.

Artifact Manifest v25 is the success commit marker. Runner validates Reservation/Lease and all frozen bindings before idempotency lookup, build, Engine or publication. required lane rebuilds Bundle/Build、执行 fresh-subprocess parity、生成 Receipt，再把 Snapshot/Bundle/Build/Receipt 收进单条 attested Decision Evidence Timeline v1 Entry；`mode=none` 只生成单条 compatibility Entry。Manifest 单独落盘 `decision-evidence-timeline.json`，Result/Fingerprint/Engine Checkpoint v8 绑定其 hash；旧四文件不再是并列权威。幂等重读校验 Timeline 及派生 hashes 且不执行 worker。Run Outcome v20 preserves typed authority/storage/Harness rejection before Engine/publication.

Step Engine may emit Engine Checkpoint v8 only after a complete source-event boundary. With a certified Artifact Store, Runner durably publishes immutable attempt/lease-generation/source-offset/hash-versioned payload and Diagnostic Checkpoint Commit v2, then passes the committed descriptor to the external control callback. The orchestrator may synchronously register Checkpoint Receipt v2 before returning continue/cancel; Runner never writes Control Plane state. Receipt v2 and both commit kinds bind the storage-policy version; legacy no-`fsync` receipts cannot authorize current resume. Prior registered files remain valid if the process crashes while producing or registering a later boundary. Cooperative cancel returns no Result/Artifact and carries the latest commit; another process may resume only with Control Plane-issued Resume Authorization Snapshot v1 based on the source Attempt's latest receipt. Resume revalidates authorization, source producer, target lease, Attempt namespace confinement, hashes, storage policy, Decision Timeline and canonical source prefix. Successful execution removes only its own versioned diagnostics; prior terminal Attempts remain isolated. Directory/object listing is never recovery authority. Capability v1 defines the remote target as conditional `If-None-Match: *`, full-content SHA-256 collision identity, strong read-after-write, Manifest-last, and abort/expiry of uncommitted uploads; no remote adapter is certified yet.

If the simulated full close leaves negative isolated collateral, Runner returns typed `liquidation-deficit-unsupported` with the breached snapshot, trigger observation, and `remaining_collateral`; it publishes neither Result nor Artifact and never invents insurance-fund, bankruptcy-price, or ADL facts.

An open position reaching manifest-bound delisting returns `instrument-delisted-with-open-position`, carries the phase-`00` terminal EventKey, is non-retryable, and commits no partial Result. A settlement price requires a separately frozen data contract; Runner does not synthesize one.
