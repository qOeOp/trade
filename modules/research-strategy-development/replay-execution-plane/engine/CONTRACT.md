# Replay Reference Engine

Owns the deterministic EventKey total order and source-bound order orchestration for Simulator v7. Same-time phases are delisting `00`, funding `10`, exact mark/risk/liquidation `15`, and OHLC market `20`. A venue-risk epoch effective at time `t` is resolved before every SourceEvent at `t`; post-entry, path, terminal Margin and liquidation fee use that snapshot and persist its id/hash. Exact breach cancels stop/target, then submits, activates, and fully fills one forced reduce-only market order at `15.3/15.4/15.5`; non-breach Mark never triggers strategy orders. The execution price is policy-modelled from trigger Mark plus adverse slippage. OHLCV breach emits failure evidence without forced execution. Generic status/halt, tick/L2 execution, partial liquidation, deficit/insurance/ADL, external commands, general multi-order matching, and portfolio reduction remain outside the certified subset.

The engine consumes an immutable request plus its bound Dataset Manifest and delegates normalization/admission before the first event. It never loads dataset locations itself, selects Candidates, evaluates promotion, writes Control Plane state, or invents unsupported fill semantics.

Engine Checkpoint v2 is a non-authoritative execution-state envelope emitted after all effects of one source event have completed. It binds request/data/simulator/numeric policy, source prefix hash and offset, entry/bracket state, order-event sequence, applied funding, risk-snapshot-bound exact-risk snapshots, limitations, and its own canonical hash. Resume must reproduce the same Result as a clean run. Cancellation is observed only at these boundaries;a terminal source event completes atomically before any later cancellation poll.
