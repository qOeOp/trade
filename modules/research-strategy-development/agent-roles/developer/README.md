# Developer

Developer 角色入口。前置 typed 入口消费 Control Plane Development Brief，生成受 Proposal、candidate space、data scope 与预算约束的 Contract Draft；Control Plane 收据仅为 `received_unvalidated`。正式 Contract 冻结并签发 Trial Reservation 后，后置 typed adapter 才可把权威 identity 与实验计划组装为 Trial-bound Replay Request。Developer 不拥有 Contract freeze、Replay Result 或晋级权；迁入的 family、candidate、signal、loop、campaign、compile package 仍须剥离治理与评审语义。
