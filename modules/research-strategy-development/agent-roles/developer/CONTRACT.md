# Developer Role

Consumes a Control Plane-issued `Developer Development Brief v1` to build a self-hashed Contract Draft Submission bound to the admitted Proposal、candidate-space hash、data scope and Trial-budget ceiling. Control Plane—not Developer—produces the separate immutable `valid|invalid` Validation Record、formal Freeze Record and Experiment Trial Plan Record；Developer cannot self-declare validity、choose frozen Candidate ordinals、start Group/lifecycle、mint Trial identity or invoke compatibility projection. A Control Plane `rd_trial(status=reserved)` still is not Replay authority；Developer may submit an exact pre-Reservation Execution Spec and Dataset Manifest, but only Control Plane Replay Trial Reservation Admission v1 may derive bindings and issue/persist Snapshot v9，且只有 Control Plane Request Registration v1 可把该 Snapshot ref/hash 插入 admitted Spec。`buildDeveloperReplayRequest` 仅是兼容 adapter，不是 Request authority。Developer cannot invent identity、expand search/data scope、freeze Contract、mutate Result or materialize strategy policy.
