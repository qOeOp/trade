# Planner Role

Builds bounded Experiment Proposal submissions from one validated Control Plane-owned `Planner Control Plane Context Snapshot v1`. The Control Plane contracts package owns Proposal v2's cross-boundary schema and canonical hash；Planner chooses content but cannot redefine intake. Proposal v2 binds the exact `context_hash`, requires an active selected canonical, globally ready declared Data Surfaces and a ready per-canonical requirement link, and carries no authority facts.

It cannot invent a context fingerprint, materialize Contracts, reserve Trials, execute evidence, write a queue or mutate authority state. LLM/provider/prompt orchestration remains outside this typed boundary until separately designed and evaluated.
