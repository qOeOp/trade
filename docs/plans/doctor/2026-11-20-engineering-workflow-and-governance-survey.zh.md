## 外部生态对标：哪些已是前沿，哪些无需跟风

在计入待改进项前，先明确核对当前仓库与 2025–2026 外部开源技术栈的对比结论，避免把“有意为之的精简边界”当成落后：

1. **已处于行业最前沿的设计（保持现状）**
   - **Skill 化架构与 A/B 回归评测**：仓库已将早期 MCP 服务（`services/video-note-mcp/`，#1507）退役为按需加载的 `.agents/skills/`（6 个 skill、36 份文档、28,094 词），并配置 `.agents/.claude-plugin/plugin.json` 使用 Anthropic 原生 `claude plugin eval .agents`（共 244 个评测用例）以及 `.github/scripts/skill-names.py` 的 CI 标识符门禁与 `skill_heat.py` 段落热度追踪。这与 2025–2026 业界从“重型常驻 MCP”转向“渐进披露 Skill + CI 评测基准（如 SkillsBench）”的最佳实践完全吻合。
   - **单一 CLI 入口与自愈拒绝码**：`python -m cli.main <noun> <verb>` 输出结构化 JSON 并在 stderr 返回带修复指令的 249 个拒绝码（`shared/refusals.py`），是 Coding Agent 工具调用的最高效形态。
   - **信任边界与底座版本**：Dolt 2.7.2 版本化研究账本、OCI 镜像 Digest 锁定回放闭包、Python 3.14、`uv`、`nautilus_trader==2.0.0rc7`（Rust v2 内核）、Node 24 原生直跑 TypeScript、React 19、Tailwind v4、Vite 8、Vercel AI SDK v7（`@assistant-ui/react`）及浏览器端 WebGPU 运行 `@huggingface/transformers` 4.3.2（TranslateGemma 4B ONNX）均已是最新一代。
2. **看似“手搓”但实为正确决策的部分（不引重型框架）**
   - **回测与执行引擎**：完全交由 NautilusTrader 2.0 Rust 内核负责，未自建回测框架或引入 LangChain / CrewAI 等会破坏确定性审计边界的黑盒 Agent 编排器。
   - **单操作员本地守护进程（`ide/ide.py`、`paper/serve.py`）**：仅负责调 CLI 与推 SSE，保持标准库零外部运行时依赖可彻底消除 Web 框架供应链断裂风险。
