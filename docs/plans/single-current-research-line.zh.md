# 每账本一条当前研究路线

> 2026-10-29 起由 [parallel-research-lines.zh.md](parallel-research-lines.zh.md) 取代（经用户批准后生效）。

2026-10-25，用户确认：每个研究账本保留一条当前路线，允许路线内分工，不开放两条路线同时推进正式研究；本项只收敛文档和待定，不新增字段、检查或调度机制。

## 当前实现与边界

- `ledger.lines.current_line` 取最新入账的路线；`registration.register._check_window` 与登记、回放绑定会读取当前路线。选线是共享账本上下文，不是每个会话各自独立的选择。
- `unclosed_lines` 将最新路线以外的路线视为已结束；`closing_commit` 的封盘点为下一条路线诞生提交的父提交。选择新路线接替旧路线，不改变既有结束和封盘规则。
- `line_trials` 按市场提交与开发窗口匹配研究试验，没有严格的逐路线身份绑定；同一数据和窗口上的不同路线可能共享试验集合。不能把多开会话或多建路线包解释为已支持两条独立路线并行研究。
- 同一路线内的资料、审查和分析可分工；正式实验仍遵守既有登记、解释、复盘和事务检查。没有放宽登记批次、复盘停点或并发写守卫。
- 单一当前路线不是执行锁，选线不会自动停止其他 Agent 或已经启动的任务。本项不添加进程取消或跨 Agent 调度，也不将它们描述为产品能力。
