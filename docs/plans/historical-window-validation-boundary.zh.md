# 历史窗口：保留探索用途，不引入降级样本外

2026-10-25。用户逐项确认：不引入“降级的样本外”类别；已有历史数据用于探索、稳健性检查与反驳，正式样本外沿用未来窗口及公共时间戳边界。本轮只同步文档，不改准入规则或运行路径。

## 已定边界

- 正式样本外沿用先冻结登记、取得时间戳、再发生窗口的现有规则；原登记及重试链的具体核对继续由现有代码处理，不修改首次登记、绑定或重试检查。
- 其他历史时段、同期标的可按现有探索路径检查稳健性、比较机制、发现失效条件、提出新假设。报告说明候选、方案、选择窗口及标的的理由、已知暴露和局限，不必因等待未来样本外而停止历史探索。
- 从未对某段数据运行过策略，不等于设计未受它影响。历史探索结果不升级为正式独立验证，不因结果好看事后改名为样本外，也不据此声称已排除过拟合。
- 这是当前产品的可审计口径，不是断言任何历史数据都被污染或所有历史留出设计都无效。当前产品没有历史留出数据隔离及暴露证明机制；本轮不新增该机制、证据等级、登记类型或存储字段。

## 现有依据与文档落点

- `registration/validation.py::validation_register` 对首次登记要求 `window_start > created_at`，否则 `REGISTRATION_TOO_LATE`；`validation_bind` 沿原登记核对公共时间戳早于窗口起点，并核对窗口、输入及环境。
- `replay/entry.py::explore` 提供既有探索回放路径，仍记录试验及执行回执。本轮不运行它，也不放松其导出、审计或其他检查。
- `research-round/SKILL.md` 已将先前未使用的开发数据子集列为条件性观察，不作为独立验证；本轮不改 skill。
- [COS 的既有数据预登记说明](https://www.cos.io/initiatives/prereg)允许在适当设计下对既有数据预登记，并要求说明此前接触、分析及其对决定的影响；它不直接证明当前产品已经具备历史数据隔离。本轮决定保留更窄的产品命名与准入口径。
- 正文 `X.2.2.2` 说明历史探索的用途和结论范围，章节末记录决定，总清单移除旧条目；保留能力编号，同步悬浮定义和图谱标题。后续独立复读、数据或环境变化两项仍保留待定。
