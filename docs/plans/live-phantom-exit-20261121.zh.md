# STOP 按交易所持仓平仓（2026-11-21）

来源：[0.5.0 重判](rejudge-0.5-20261121.zh.md) C-140；doctor 20261114-25。回归门：回环夹具 `tests/live_loopback/test_external.py`（#3334）。

## 问题

在运行之外平掉的仓位（手动平仓、强平、ADL）不会并进 rc7 的缓存，缓存里的仓位就成了幻影。STOP 按缓存发平仓单，被交易所拒；运行以 `unresolved` 结束，交易所上还留着那张仓位的止损单。回环夹具在真实的 rc7 Binance 适配器上复现了手动平仓和强平两种情形。

## 决定

2026-11-21，用户委托：「需要我定的部份最后也是一样由你决定按推荐做」。按推荐做：

- STOP 路径在发第一张平仓单前读一次交易所（REST）。同一合约同一方向上，运行的各个仓位依次分配交易所的持仓量。
- 交易所足额持有的仓位照旧原生平仓。持有不足的只平交易所还有的量，记一行 `venue_closed`，不再按缓存平。
- 其余仓位都平掉、运行的挂单（包括孤儿止损）都撤掉以后，运行以 `venue_flat` 结束，和启动时发现交易所全空的处理相同。
- 读取失败或读回无法解析时，照旧按缓存平仓，并记 `stop_read_failed`。

## 还没做

20261114-25 的另外两项仍开着：同一运行换新原生身份后继续交易，以及止损覆盖检查先于比对。
