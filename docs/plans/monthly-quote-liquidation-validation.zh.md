## 保留的证据缺口

### 五月参考源断连，不能当作连续参照

2026-05-01 的 CSV 本地接收时间从 UTC `06:10:59.135077` 跳到 `06:11:11.508658`，相差 **12.373581 秒**。原始 API 的 06:10／06:11 两分钟切片分别在末端／开端出现空行；[Tardis 原始 API 文档](https://docs.tardis.dev/api/http-api-reference)将空行定义为采集断连标记。本次保留相邻原生消息与原始响应，未填补缺口、修改时间戳或换交易所输入。

该日强平发生在断连之后，缺失段内是否本应更早触发，现有参考数据不能排除。十二天虽都覆盖 1440 个捕获分钟，仍不能排除分钟内断连。其他日期未发现上述顺序或价格异常；CSV 没有逐消息连续序号／断连标记，本次仅针对最大间隔额外回查原始 API，未认证所有秒级区间完整。

### 推算按 T、观测按 E，不把差异全归为价格推算

[Tardis CSV 说明](https://docs.tardis.dev/downloadable-csv-files/data-types.md#book_ticker)中的 `book_ticker` 来自交易所原生 BBO，区别于 L2 重建的 `quotes`；`timestamp` 和 `local_timestamp` 单位均为微秒。当前公开 [Binance mapper](https://github.com/tardis-dev/tardis-node/blob/master/src/mappers/binance.ts)用 bookTicker 的 **E** 作事件时间，缺失时回退接收时间。核对 2025-10-01 00:00 原始切片前 1000 条：CSV 全部等于 E×1000，接收时刻及价格匹配，149 条 E≠T。抽样与当前 mapper 不构成历史转换器版本认证。

推算侧沿产品 aggTrades 的 `transact_time`（**T**），观测侧沿 CSV 的 **E**。两侧均 `ts_init = ts_event`、零额外接收延迟；`local_timestamp` 只用于质量核对。差异同时含成交时点与报价发布时点因素，不能全归为价格推算误差。实际记录接收减事件时间约 1.214 ms–2.08144 s，既不是本夹具模拟的延迟，也不能当作纯网络延迟。

扫描的全部事件时间均落在毫秒网格，旧脚本微秒转毫秒在这批文件上没有额外丢精度；这不补足 T/E 语义差异或其他日期的精度证据。

四个旧日期（2025-10、11，2026-02、08）的方向、费率、条数、入场、强平与期末现金均逐项复现。旧 `compare_true.py`、JSON 及日志仍在；**旧 Tardis 原始文件和当时 SHA-256 未找到**。旧脚本读市场表时未钉提交、依赖宿主工作树，也未钉 OCI 镜像。本次重下十二份原件并记录 URL、响应头、下载时间、大小与 SHA-256；Tardis 响应没有独立签名的历史哈希。本次哈希只标识本次取得的字节，数值复现不恢复旧原件的逐字节身份。

## 夹具边界与仍未覆盖范围

本金 100,000 USDT，目标名义额 1,000,000 USDT（约 10 倍），数量按 0.001 BTC 步长取整；每侧在自己的第一条报价入场，之后无策略订单。相同配置不保证两侧入场时刻或价格相同（八月差一档），现金差也含入场差异。maker／taker 费率为假设的 0.0002／0.0005。

历史夹具用两份全天输入的极值预先选择压力方向及费率，含全日信息；不是因果策略或 Binance 真实保证金档位。没有深度、队列、资金费、后续信号、计时器或旧挂单情景。直接原生工程夹具不走产品正式 replay／审计／封存链，不产生研究经济证据资格。

因此仍缺其他合约、完整时段、相反方向、50 倍等其他敞口及真实交易所强平规则的适用性证据。不能据此宣称全年推算源、所有强平研究或最大回撤／收益目标已验收。原有逐合约、时段与用途验证边界保持不变；不自动删币、缩窗或设新阈值。2025-10／11 整月导入读数未完整持久保留的问题也不由这次十二个首日核对补齐。后续 [整月事后补证](quote-readings-posthoc-202510-11.zh.md)已确认两个月 61 天、93,261,348 条状态与固定快照逐条一致；旧提交和当时读数凭证缺失的事实未改，也不补足本页的独立参考报价缺口。
