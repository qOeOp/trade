# IDE 设计语言：间距、尺寸与对齐

2026-11-08 用户看了 Runs 页的图表卡后说：图表卡的左边距、上边距不美观，和别处不协调；很多按钮做得太胖，这个产品更适合细长、窄边距；希望有一套统一的设计语言（固定的圆角、调色板、边距等），不要一块块补。用户指定 Details 面板头部的边距作为基准。

本文是规范，不改产品代码。迁移是之后的一个 PR（见「迁移」）。

## 结论

- **颜色、字号、圆角、阴影已经统一，并由代码强制，本文不改它们的值。**
- **间距、控件高度、线宽、焦点样式没有统一。**
  - 间距类出现 843 次，其中 98 次落在下面的档位以外，分布在 38 个文件。
  - 控件高度有 20、24、26、28、32、36、40、44 八种。其中 40/44 是 Live 的 16 个组件文件里写死的 `min-h-10`/`min-h-11`，在宽屏桌面上也生效。
- **基准是 Details：文字离 island 左边 12px，头部一行 40px。** 所有 island 和卡片的头部、正文、表格都按这个对齐。
- **间距只用 8 档：1、2、4、6、8、12、16、24px。** 控件高度桌面只有 4 档：20、24、28、32px。
- **文字对齐内边距，不对齐控件的点击区。** 一行开头的控件有自己的水平内边距时，整行按这个内边距向左收回，让文字落在 12px 线上。
- **手机只放大，不另换规则。** 手机尺寸由 `:root[data-phone]` 的 token 给出，不用 `sm:` 这类视口断点改尺寸。
- **规则写进 `scripts/check-rules.mjs`。** 档位以外的间距、任意像素值、在调用处覆盖控件高度、用断点改尺寸，都会让构建失败。以后不会再一块块补。

## 规范

### 网格与间距档位

4px 网格，加 2px 和 1px 两个细档。Tailwind 的 `--spacing` 保持 4px（手机 4.5px）。间距类（`p*`、`m*`、`gap*`、`space-*`，含负值）只用这些档位：

| 类 | 像素 | 用在 |
|---|---|---|
| `px` | 1 | 细线占位、边框对齐 |
| `0.5` | 2 | 紧挨的控件之间（图标按钮组、标签页组）、日历格子之间 |
| `1` | 4 | 控件内的小间隔、popup 外框内边距、island 之间（`--gap`） |
| `1.5` | 6 | 图标和文字之间 |
| `2` | 8 | 控件的水平内边距、卡片里的行间、表单项之间 |
| `3` | 12 | **island 内边距**、一行读数里各值之间、块与块之间 |
| `4` | 16 | 对话框内边距、大块之间 |
| `6` | 24 | 空状态的内边距、段落组之间（只用于这两处） |

`0` 照常可用。另外允许三种写法：

- 引用 token：`p-(--half-gap)`，需要新的固定距离时先在 `tokens.css` 加 token；
- 安全区：`env(safe-area-inset-*)`，可以和档位内的值相加；
- `em` 值：只用于随字号缩放的地方，例如热力块里的文字。

其余的任意值不允许：像素、`rem`、`calc` 修补都不行。内联样式里的间距只能是档位内的数字，或具名常量（树的缩进是 `TreeRow` 的 `TREE_INDENT`，20px，即 16px 图标加 4px 间隔）。

位置类（`top-[14%]` 这种居中定位）不是间距，不受档位约束。

### 各容器的内边距

| 容器 | 内边距 | 说明 |
|---|---|---|
| island | 水平 12px（`px-3`）；没有头部时上边 12px | 文字左缘离 island 边缘 12px |
| island 头部 | 40px 一行（`--header-h`），水平 12px | 用 `PanelHeader`；13px 字号、1.45 行高的文字在 40px 里垂直居中，字形顶部离上边约 12px |
| 表格 | 首末列 12px，单元格之间 12px | 和 island 内边距对齐；现在的 20px 改为 12px |
| 卡片（`rounded-card`） | 水平 12px，垂直 8px | `Section` 已经是这个值 |
| popup、菜单 | 外框 4px，菜单项水平 8px | 菜单项文字离 popup 边缘 12px，和 island 一致 |
| 对话框 | 16px（`p-4`），页脚上下 12px | `LiveDialogFrame` 现在是 20px，改为 16px |
| 一行读数 | 值与值之间 12px，名字与值之间 4px | 图表读数已是这样 |
| 提示条（左边一条竖线） | 竖线 2px，文字离竖线 8px | 现在是 10px 或 12px 两种 |

嵌套时圆角按外层减内边距取最近一档：island 10 里的卡片 6，卡片里的控件 4，控件里的 badge 3。

表单在宽列里最宽 560px（`--form-measure`），不随列拉宽；页脚按钮仍在列的右端。键值对用固定标签列（`KeyValues labels="fixed"`，`--key-column`），同一屏的几组键值共用这一列；窄列里的只读摘要改为名字在上、值在下。

### 控件高度

桌面只有 4 档，全部由控件组件自己给出，调用处不覆盖高度：

| 高度 | 写法 | 控件 |
|---|---|---|
| 20 | `h-5` | 行内控件：读数里的开关、`PaperButton`、badge；`TextButton` 的行内尺寸 |
| 24 | `h-6`/`size-6` | 图标按钮、菜单项（现在 26，改为 24）、Segmented 里的每一项、树的行（`--row-h`） |
| 28 | 新增 `--form-h` | 表单按钮、输入框、下拉框、Segmented 的外框、表格行（现在 36，改为 28）；`TextButton` 的表单尺寸 |
| 32 | `--frame-control` | 工具栏和侧栏的控件、头部里的标签页（`Tabs`） |

- **细长**：控件比现在矮，水平内边距 8 到 12px，不靠加高来显得重要。主要操作靠填色（`primary`）区分，不靠尺寸。
- **表格行从 36 改为 28** 是这次最显眼的变化，同一屏能多看约三成的行。
- **`TextButton`** 现在由调用处写高度：读数里写 `h-5`，图表卡的 Fit 写 `h-7`。迁移时改为组件的尺寸参数：随文字行（默认）、行内 20、表单 28。行首收回照「对齐」一节由行容器负责；几处行内链接已有的 `-ml-1`/`-mx-1` 在档位内，保留。

### 按钮的种类

高度之外，按钮的种类由它所在的位置决定，不由操作的重要程度决定：

| 位置 | 用 | 样子 |
|---|---|---|
| 表单、弹窗底栏（填写、提交、取消、下一步） | `FormButton`，主操作 `primary` | 有边框或填色，`--form-h` |
| 头部（40px 那一行）里的操作 | `TextButton size="form"` 或 `IconButton` | 无边框，蓝字（`--link`）或图标，悬停才有底色 |
| 读数、信息行里的操作（展开、开关） | `TextButton size="inline"`；复制用 `IconButton` 的复制图标 | 无边框，20px，蓝字 |
| 正文里的一个独立操作（某一节的主要按钮、空状态的入口） | `FormButton` | 同表单 |

- 有边框的按钮在头部和信息行里显得粗重；手机上 `--form-h` 是 44px，更明显。
- 文字按钮一律是蓝字（`--link`：浅色 `#306DE6`，深色 `#548AF7`，都过 4.5:1），不加下划线，和同字号的正文分开；只有带状态含义的颜色（例如 misses 色的异常数）覆盖它。列表里的选项（菜单的一行）不是文字按钮，保持正文色。
- 同一个操作只放在一处：工具栏已经有的（例如 Review run…），画布里不再放。
- 这一条目前没有写进 `check-rules`：位置不能从类名判断，靠评审。

### 对齐：文字对齐内边距

一行开头的控件如果有自己的水平内边距（标签页 8px、文字按钮 4px），**整行容器**向左收回同样的距离，使文字落在 island 的 12px 线上，点击区伸进内边距。

- **由行容器收回，不由控件收回。** 收回量写在行容器上（例如 `-ml-2`），不写在控件上。这样行换行后，新的一行同样收回；控件自己不知道它是否在行首。
- **分隔线不占宽度。** 行里的分隔线画成零宽元素上的伪元素细线（`before:`），左右间隔由相邻控件的间隙给出，不再用外边距。这样行首收回量只等于控件内边距，图表卡的 `-ml-[17px]` 和 `MetricStrip` 的 `calc` 修补都去掉，改为档位内的负外边距（例如嵌套的 `-ml-3` 与 `-ml-px`）。

### 头部

每个 island 和带标题的卡片用 `PanelHeader`（或同尺寸的变体）：40px 一行，水平 12px，左边是标题或标签页，右边是图标操作。图表卡的阶段与图表切换（`ChartSwitches`）放进这一行，不再自己写 `px-3 pt-3 pb-2`。

### 线宽与焦点

- **1px**：所有边框、分隔线、输入框边框、悬停时的环（`ring-1`）。
- **2px**：只用于三处：
  - 表示状态的线：标签页下划线、选中、提示条和引用块的竖线；
  - 圆点在底色上的镂空；
  - 键盘焦点。
- **焦点只有两种样式。**
  - 一般元素用 `base.css` 的 2px 蓝色外框；外框会被滚动区裁掉的行和格子（树的行、运行卡片、日历格），同样的 2px 蓝线画在内侧（`ring-2 ring-inset`）。
  - 文本输入框用 1px 边框变蓝（`focus:border-focus`），不加环。
  - 其他自绘焦点（`focus:ring-1`、`focus-visible:ring-2`）改成这两种之一。

### 手机

手机保留桌面的形状和细节，只放大尺寸（`docs/plans/ide-mobile.zh.md`）。所有放大都写在 `:root[data-phone]` 里：

| token | 桌面 | 手机 | 影响 |
|---|---|---|---|
| `--spacing` | 4px | 4.5px（已有） | 所有间距和用档位写的尺寸放大 1/8，图标按钮 24 → 27 |
| `--row-h` | 24px | 40px（已有） | 树和列表的行 |
| `--header-h` | 40px | 44px（已有） | island 头部 |
| `--frame-control` | 32px | 36px（已有） | 工具栏、标签页 |
| `--form-h` | 28px | 44px（新增） | 表单按钮、输入框、表格行，可触控 |

- **图标按钮**用 `size-6`，随 `--spacing` 放大到 27px，不改用 `--row-h`。否则手机上每个图标按钮都会变成 40px。
- **不按视口断点改尺寸。** 组件里不用 `sm:`、`md:`、`lg:` 改高度、间距和尺寸。
  - 这样做的原因：窗口窄于 768px 时页面已经是手机外壳（除非用户选了「Desktop layout」），断点改尺寸只会让桌面窄窗口得到触控尺寸。
  - 按容器宽度改排列（`@container`、`@max-md/page:`）照旧可以，但其中的间距也只用档位。

## 强制

在 `scripts/check-rules.mjs` 加五条，与现有规则一样让 `npm run check` 和构建失败。每条规则旁边的注释写明理由，并指向本文：

1. **间距档位。** `.tsx`/`.ts` 里间距类（`p*`、`m*`、`gap*`、`space-*`，含负值和任何变体前缀）的数值只能是 `0`、`px`、`0.5`、`1`、`1.5`、`2`、`3`、`4`、`6`。
2. **任意间距。** 间距类的方括号值只允许 `env(safe-area-inset-*)`（可与档位相加）和 `em`；引用 token 用圆括号写法。内联样式的 `padding*`、`margin*`、`gap` 只能是 token 或档位常量。
3. **控件不被覆盖高度。**
   - 传给 `FormButton`、`IconButton`、`TextButton`、`Tabs`、`Segmented` 的 `className` 里不许出现 `h-*`、`min-h-*`、`size-*`。
   - 也不许用 `[&_button]`、`[&_input]`、`[&_select]` 这类后代选择器改高度。
   - 检查按整个 JSX 元素（到 `>` 为止，可跨行）匹配，不只看单行。
4. **不按断点改尺寸。** `sm:`、`md:`、`lg:`、`xl:` 不许接高度、间距和尺寸类。
5. **CSS 文件同样受约束。** `tokens.css` 以外的 `.css` 里：
   - `font-size` 只能用 `var(--size-*)` 或 `em`；
   - `padding`、`margin`、`gap` 的像素值只能是档位。

`check-rules.mjs` 开头说「Each rule names its reason in the design (README, "Code rules")」，但 `ide/web` 没有 README，这句指向的说明不存在。迁移 PR 把这句改成指向本文。

## 迁移

一个 PR，基于 `main`，只改 `ide/web`，这样 Live 运行时服务器也能只发布 Web。规则和迁移在同一个 PR 里落地，合并时代码已经全部合规，不留白名单。

1. **token。** `tokens.css` 加：
   - `--form-h`（桌面 28、手机 44）；
   - `--field-key`（44px，输入框末尾给 Tab 提示留的位置）；
   - `--size-field`（16px，手机输入框的字号，低于它 iOS 会放大页面）。
2. **控件组件。**
   - `FormButton`、输入框、下拉框、表格行用 `--form-h`；
   - 菜单项改为 24；
   - `TextButton` 加尺寸参数。
3. **Live 组件。**
   - 删掉 16 个文件里的 46 处 `min-h-10`、`min-h-11`、`sm:min-h-*`，以及 `LiveDialogFrame` 的后代选择器；
