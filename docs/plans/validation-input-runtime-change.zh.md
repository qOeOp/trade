# 进行中的样本外登记：数据修正与运行环境变化

2026-10-25。用户逐项确认本方案，明确授权固定登记时的账户基准及相应绑定检查。范围限于现有样本外登记、重试、skill 和文档，不增加作废状态、释放命令、表或存储字段。

## 已定边界

- **尚未绑定**：正常补齐或修正行情后，仍满足最初登记的成员、覆盖和其他准入条件，就沿用原登记执行一次。保留新旧市场提交及修正证据，不因数据变化另获验证机会。
- **已经消耗**：沿用现有中断、无效、无经济证据重试条件；候选、窗口、范围规则与完整检验设计保持最初声明。已有经济证据的成功运行不因亏损或数据修正变成可重试；保留原结果并披露修正影响，不覆盖原记录或声称另一份独立验证。
- **账户基准**：从 `retry_of` 链最初登记的诞生提交读取当时该源码最近一次通过的研究运行，以其开始回执的 `account` 为基准。后来的研究、事后补跑和重试登记都不能替换它；最初没有基准则拒绝，不能事后补足。执行方式、保证金、强平等条款已在既有 `account` 内，无需另存。
- **成员与设计**：重试仍按最初登记的市场提交、登记月份与范围规则核成员。完整 `design`（包括 seed、alpha、minimum_effect 和理由）不可在重试时改换；旧版本已写入但尚未执行的变更设计重试保留原行，绑定时拒绝。
- **镜像变化**：主分支更新不自动作废登记，也不强制换镜像。确需升级时，Agent 按既有原生配对流程确认实际对照范围内的兼容性；不能证明兼容或撮合、保证金等实质条款变化时停止旧验证，由用户决定新的未来窗口。代码继续核正式 main 构建，不新增自动兼容裁决或通用数据修正分类器。
- **停止与说明**：用现有追加证据和判断注明登记编号、账本提交、新旧市场提交、镜像身份及原因。没有作废状态、自动释放预留或虚构执行来消耗登记；停止不会解除现有预留。未来窗口仍由用户明确指定。

## 实现与职责

`registration/validation.py` 在绑定中沿用最初登记核成员与设计，并用既有 `ledger.read_as_of`、`trials.latest_research` 和 `register.control_trial` 从不可变提交派生账户基准。拒绝仍在试验写事务内发生，整笔回滚，不消耗登记。重试登记也核完整设计，不改既有成功／失败重试资格。

`ledger/refusals.py` 与 `validation registration --help` 说明固定基准及下一步，移除“先补跑当前环境的研究即可解决”的错误建议。样本外 reference 说明修正、兼容性、披露及交接；开发环境重建 reference 明确转读该边界，避免把开发重建当成额外验证机会。没有修改 Nautilus、执行模型、依赖、用户研究目标或活动研究。

文档同步 `X.1.3.1`、`X.1.3.2`、登记 API、数据库字段说明、skill 设计页与悬浮定义；移除章节和总清单中的本项待定。保留真实样本外交付尚未完成的待验证标记。顺便修正被触及 API 文档中已不存在的 `inputs` 参数，实际输入仍从开始回执读取。
