## 登记与执行

初始实验使用 v2 attempt：`contract` 保存 `scope/plan`，`registration` 只含 `status`，第一次事前发表必须为 `pending/pending`。Dolt 原子发表返回真实初始 ID/revision/commit，执行前绑定该回执。合同和 `strategy_binding` 在同一 attempt 内冻结，改变意图或源码须登记新实验；后续只修订决策、证据和实际对照索引。Git 不再保存新实验凭证文件，也没有元数据后端或旧登记兼容入口。

已有封存报告保留原始字节、路径、哈希和当时身份；不能用本次迁移补造早年的启动登记或事前预测。固定历史原文仍通过 `research/records/history.json` 和历史证据引用读取，资料导入只负责归档保管。

新回放继续走 `research.records.artifacts run`，先从固定 Dolt commit/revision 导出策略，再核对镜像实际 manifest digest、平台、镜像内依赖和共享代码身份，解析实际默认配置并计算配置 digest。镜像内 `BacktestNode` 回放及同镜像审计只挂载只读策略和规范输入、可写报告目录。隔离约束与环境版本固定是两件独立能力，二者均记录实际观察。

## 工作台发现与剩余边界

受影响任务为 `D105-01` 至 `D105-05`：从 Dolt 导出真实策略变体并沿同一原生路径运行。旧共享入口将 H19a 选择、仓位约束和诊断字段写死，其他完整源码仍需要旧产品模块或自建报告脚本；日线预热在原生桥接中也没有显式传输。最小共享改动是让策略源码提供配置校验、诊断及完整性 hooks，桥接传输预热配置，共享入口保留数据准备和原生事实。没有新增策略语言、研究调度或模拟交易账本。

真实样本也暴露专用分层审计不能覆盖普通退出和分段退出。补充通用原生报告审计后，验证身份、数量、成交与持仓链接、原生费用/资金费调整、最终保护及账户余额；专用 tier 审计保留原规则。通用审计明确不重建信号、目标几何或历史每一步保护，不重算资金费率。初轮迭代成本为 196 个共享能力测试（含真实隔离 Dolt）与五个代表配对、一次 37 币回放；这些证据用于框架验证，不能作为独立策略确认。

复查还复现两处通用审计漏检：`FILLED` 状态下成交量不足，以及持仓开平仓引用指向错误的首末成交。共享审计现要求全成交数量一致、持仓事件时间不倒序及首末引用准确，并以取消后的部分成交、分段多次退出作为正例。最终 199 个测试全部通过。修复后的固定镜像为 `sha256:d7f3536ec448a20629ae0431560bcaca8c37fb9d9ea396f3b378451ff91ae37c`；另立 `D106-native-audit-repair-20261009`，复验分段退出的原生路径，并在该镜像中复查六份原报告，具体观察及决定留在 Dolt。

正式研究的长期保留与异机恢复由具体合同另行定义。后续台账设计继续以 Agent 实际研发任务的阻塞和使用成本驱动，清空 demo 的时点由用户选择。
