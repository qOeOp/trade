# 账本图与会话图的差异要不要进账本：字段审阅

2026-10-23。用研究图检验账本能否还原一次研究：同一条研究线 `research-line-20261022-ema-cross-btc-daily`，一张图只从账本读，一张图只从会话 01a163c6 的转录读，再逐项对比。对比找出几处会话有、账本没有的信息，以及读账本时的几处不便。按 AGENTS.md，加存储字段前先做独立子 Agent 审阅，结论记在这里。依据 origin/main 06611b672。

## 对比结果

候选、父版本、研究回放、读数、资格、推荐两边一致；预测及其结果、源码审阅历史、对照、职责和假设账本记得比会话更全。账本没有、会话有的，是下表前四项；第五项是读账本时的不便。

## 路线归属与多重比较的 N

`ledger.line_trials` 按交易窗口与市场提交判断试验属于哪条路线。换线而窗口与市场提交不变时，旧路线的试验也会算进新路线。逐处核对：复盘停点 `REVIEW_DUE` 与未复盘试验只数新路线建立之后的试验，不受影响；“有试验未解释”闸门不限定判断写在哪条路线上，旧路线已解释的试验算作已覆盖，只有旧路线留下跑完却未解释的试验才会卡住新路线，而每次开始会先关闭未关闭的路线；`trials_on_line` 计入旧路线在同一份数据上的试验，这些都是同一开发数据上的搜索暴露，多算是保守的。结论：不改代码，在设计文档写明 N 的口径。
