# 按设计文档重构实现：分阶段计划

2026-10-18 用户启动。规格是已合并的研发长链设计文档（文档站各章与设计页）；现行代码（`backtest/`、`research/market/`、`research/records/`，约 6000 行）按它重写。

## 原则

- **文档是规格。** 每个阶段只实现设计页写明的函数、表与拒绝；发现设计缺口或矛盾，先改文档再写代码。
- **自下而上。** 先账本与登记，再回放与报告，最后命令行、skill 与切换；下层不知道上层。
- **并存后切换。** 新包和现行代码并存，现行流程照常可用；切换那一步一次换掉命令行与 skill，随后删除旧代码，不留兼容层。
- **测试只用一次性账本。** 每个阶段的 Dolt 集成测试在临时服务上跑（Dolt 2.4.2），从不写正式账本。
- **镜像内的改动集中做。** 改引擎、审计或指纹会产生新镜像，按 AGENTS.md 做配对原生重放证明行为不变；这一步要拉取 CI 构建的镜像，须用户允许下载。
