# 报告存储字段决定

2026-10-18。按新存储条款（账本只存回放给不回来的东西）重定一次封存运行在账本里的存法，并按 AGENTS.md 先交独立 Agent 审阅新增字段。依据：用户同意的「一套度量目录、两种报告、其余动态」，以及 [账本存储审计](ledger-storage-audit.zh.md)。

## 决定

一次通过的封存运行，账本只存四样：

| 存什么 | 内容 | 为什么不能派生或靠重放 |
|---|---|---|
| 运行行 | 状态、引用审计发现的无效原因、审计 {是否跑完, 发现清单}、原生报告的语义指纹 | 审计发现与指纹是封存时的观察；指纹是账本与缓存之间唯一的连接 |
| 封存结果（新表，以运行与代码版本为键，只追加） | 资格事实（每项是否通过、原因码与计数）、标记价回撤及区间与主导合约、资金使用峰值与在市时间、锁定保证金峰值、按流动性方向的手续费与成交额、订单漏斗、计划统计是否成立、本运行特有的局限 | 都要用逐分钟敞口、账户状态或订单明细；这些原件移出账本后，每次读都重放不现实 |
| 逐日序列 | 日收益，加一列当日平均名义敞口 | 配对检验的唯一单位；平均敞口在逐分钟敞口移走后无处可算 |
| 持仓周期（新表，代替持仓报告逐行） | 合约、方向、开平时刻、已实现盈亏、手续费、资金费、期末浮动、计划标签、最后一张平仓单的类型与非计划标签；价格盈亏为虚拟生成列 | 交易结构、交易配对、出场类别、逐合约与逐月下钻都要逐周期的事实 |

移出账本：订单、成交、账户、订单事件、持仓五张逐行表，费率视图，运行行上的原生摘要全文、运行环境检视、镜像修订、引擎版本、依赖锁、有效配置、输入身份、逐分钟敞口和全部指标列。执行身份只在登记包与开始回执里存一处。

能从持仓周期与逐日序列算出的量（年化、计划胜率、利润来源、交易结构、品种与方向、时期、市场暴露、仓位择时、夏普）不存，由两种报告共用的读时函数按「度量名@定义版本」计算。

## 审阅意见与处理

| 级别 | 意见 | 处理 |
|---|---|---|
| 阻断 | 重放确定性只测过市价单 | 列为第 8 章待验证：括号单、OCO、限价、部分成交、下架结算、多计划同刻下单换进程双跑；镜像固定哈希种子、按平台清单摘要钉死；源码审查加「无墙钟、无未设种子的随机数」；某种订单机制首次出现时封存流程自动双跑 |
| 阻断 | 语义指纹的计算方、覆盖范围与排序没定 | 在运行镜像内计算，身份即镜像摘要；覆盖订单事件与敞口；随机编号按首次出现顺序重编；按全部非随机列排序；每表给行数、整表哈希与逐 UTC 日哈希；字节哈希只给逐字节稳定的账户、日收益、敞口 |
| 应改 | 单运行报告存了可派生的量 | 收窄为推不出的指标；其余读时算 |
| 应改 | 总体与局限每运行重复存 | 总体是目录常量，样本量按总体名记一次；局限只记本运行特有的 |
| 应改 | 金额用 JSON 数字会丢精度 | 金额存十进制字符串 |
| 应改 | 代码版本与目录版本混为一谈 | 代码版本作为封存结果的键；每个指标带自己的定义版本 |
| 应改 | 资格读时要逐行重算 | 封存时逐项跑完存事实；新判据缺事实时标「未评估」并写进局限 |
| 应改 | 读执行身份的读者没改接 | 可比资格、受影响运行、跨镜像比较改读试验行、开始回执与登记包 |
| 应改 | 跨镜像一致性比较没有参照原件 | 参照侧先用原镜像重放并核指纹，再比较 |
| 应改 | 平均名义敞口口径未定 | 当日全部 K 线标签上名义绝对值之和的平均，空仓计零，不含预热，最后不满一天按实际根数 |
| 应改 | 持仓周期利润四列可互推 | 存已实现、手续费、资金费；价格盈亏为虚拟生成列，未平为空 |
| 应改 | 出场类别是派生值 | 改存最后一张平仓单的原生类型；平仓标签只存非计划标签 |
| 应改 | 分批平仓只记最后一张平仓单 | 写进局限并列待验证；第一个分批出场的策略出现时再审查 |
| 应改 | 口径升版后旧运行怎么办 | 封存结果以运行与代码版本为键，升版追加新行，不改旧行 |
| 可选 | 重放能给无资格运行再生原始表 | 重放出的表对无资格运行只作诊断，不能用于经济统计 |
| 可选 | 视图要的年化与回撤做成生成列 | 不做：运行视图只给身份与状态，指标经报告读口取 |
