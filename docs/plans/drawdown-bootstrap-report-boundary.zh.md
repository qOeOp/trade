# 回撤块自助分布：不纳入默认正式报告

2026-10-25。用户逐项确认：块自助回撤分布不纳入默认报告，也不作为资格或策略优劣的判断依据；保留实际历史路径上的最大回撤及现有目标、检查。本轮只收敛文档。

## 决定与理由

- 正式最大回撤继续取封存报告的分钟 MARK 权益路径，结合资金使用率、峰谷、持续时间和贡献合约解释。
- 对已实现的日收益分块重排，不会重新执行策略的仓位调整、保证金占用和原生强平逻辑。合成路径受块长、窗口和原样本阶段影响，不能直接表述为真实策略未来回撤的概率。
- 日频合成路径的回撤与分钟采样的 MARK 最大回撤不是同一统计口径，不能将前者作为后者的置信区间。
- 不新增回撤分布字段、默认图表、测量目录条目或检查；不改变配对检验、报告资格、研究目标及现有 skill 的回撤读取要求。这是明确不纳入默认报告的决定，不保留为待实现能力。

## 现有实现依据

- `ledger/metrics.py::mark_drawdown` 从初始本金及按 K 线收盘采样的 MARK 权益读取峰谷最大跌幅，并声明未观察根内权益。
- `report/comparison.py::paired` 对账户日对数收益差作循环块自助，当前不计算回撤分布。
- 报告正文在现有最大回撤段落解释该决定，章节末记录确认结果；章节和总待定清单均移除旧条目。中英文入口仍遵循现有待翻译镜像约定。
- 方法参考：[arch 的时间序列块自助说明](https://bashtage.github.io/arch/bootstrap/timeseries-bootstraps.html)；[Goldberg 与 Mahmoud 的回撤研究](https://arxiv.org/abs/1404.7493)。上述不纳入决定结合了当前产品的日频输入、分钟回撤口径及原生执行边界，不声称这些来源证明所有回撤自助方法均无效。
