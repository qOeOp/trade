## 决定与改动

- 修订 product-doctor 现有 `references/lenses.md` 的 Removal test，沿用风险、替代机制、实际作用的检验，不新增删除流程或产品门禁。只涉及审阅、新增或修改时触及的对象，不批量为全库建立逐条证明记录。

- 未触发或证据不足继续记为未验证，不据此删除，也不因此认定规则有用。确认没有独立作用、被现有机制充分覆盖或只增加无用手续的，提出删除或合并；有独立保护的边界即使从未触发仍保留。拒绝、审计与授权边界变更仍遵守用户明确授权要求，诊断不授予实施权限。
- 没有新增逐条规则证明表、存储字段、调度器或强制把所有 skill 指导改成代码的要求；没有删除具体检查、规则或历史记录。
