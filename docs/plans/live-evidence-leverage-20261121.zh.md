# Live 准入要求回放证据的杠杆与运行杠杆相同（2026-11-21）

来源：[0.5.0 重判](rejudge-0.5-20261121.zh.md) C-083（并入 D-232）；审计 [R3 B-04](doctor/2026-11-14-pre-production-audit.zh.md)；doctor 20261121-50。

## 问题

Live 准备一次运行时，`live/runs.py` 的 `_evidence` 按源码、合约、`bars`、状态与回放代码挑回放证据，不看它的杠杆；运行杠杆由用户在 Live 页选。于是一份 3 倍的回放可以作 20 倍运行的证据，回放里的保证金与敞口不代表实际运行。

## 决定

2026-11-21，用户委托：「需要我定的部份最后也是一样由你决定按推荐做」。按推荐做：

- 回放证据的杠杆取自它封存的有效配置（`input_coverage.effective_config.account.default_leverage`），不新增字段。
- 准备运行时只记录杠杆与运行相同的回放。一份都没有时，运行只能用来检查账户，启动时拒绝 `LIVE_EVIDENCE_MISSING`（#3382 起），提示按运行的杠杆补一份回放。
- 清单里记录的证据与页面预读的证据形状不变：运行自己的杠杆已在清单的 `config.leverage`。页面预读不知道用户会选的杠杆，所以仍列出全部候选证据，准备时再核对。
