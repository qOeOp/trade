# 按需市场扫描场景

用户或外部 Agent 查询当前标的、市场数值或策略信号。Agent 选择过滤条件并解释结果；产品提供已有数据查询与原生回放能力，不新增扫描部门、调度器或观察引擎。
运行策略持续消费原生行情寻找入场机会，不依赖扫描任务唤醒。

## 普通查询

例如"哪些永续合约成交量达到这个阈值"：Agent 直接调用 Market Data 的标的、快照与受支持过滤入口。
查询绑定市场范围、数据类型和评价时刻；不要求策略 Artifact 或研究项目。Agent 也可用宿主工具对获准返回值作进一步分析。
服务返回实际数据截面、覆盖、完成项和具名缺口；不认识的规则返回能力缺口，不自行编造指标或替换条件。

## 有状态策略观察

例如"哪些标的按 R-1 的历史规则，目前仍处于等待入场状态"：

1. Agent 选择准确封存的原生 Strategy Artifact、标的、输入前缀、评价时刻与资源上限；可观察未部署或未合格版本。
2. Market Data 准备并绑定满足暖机/判断的数据，按标的保留覆盖与缺口。
3. Backtest 复用已有原生回放路径重建模拟状态并输出信号；不连接真实交易凭据，不读取或修改运行实例的可变状态。
4. Agent 读取结果并解释；需要研究沉淀时由 R&D 保存实验、结果引用和发现，不增加 R&D 观察 Host。

需要历史路径的信号必须有完整输入前缀和准确规则版本；当前快照不足时不能假装已重建状态。
模拟状态、订单和持仓不能说成真实账户状态，研究信号也不签发资格或部署授权。

## 完成、恢复与边界

- 数据/回放任务由实际执行服务持有；异步工作按稳定任务身份读回，断线后先解析原任务，不盲目新建或释放承诺。
- 返回评价时刻、输入版本、标的集合和完成覆盖；空结果、部分缺口、过期和未知分别陈述。
- 不把单标的失败隐藏掉，也不把部分覆盖称为全市场完成。未执行不得声称没有机会。
- 保护读取、预算及试验暴露规则与其他入口一致；观察不能产生真实订单、激活或账户写入。
- 定时唤醒 Agent 由宿主负责，产品不新增定时扫描或部署提案。

## 实现与验收

普通查询验收数据截面、过滤结果、缺口与权限；有状态观察验收原生回放输入、状态重建、信号、异步恢复和真实效果隔离。
复用已有服务端口并只补具体故事缺口，不为找币另写引擎。职责见 [R&D](../owners/rd.zh.md#on-demand-read-only-opportunity-discovery)、[Market Data](../owners/market-data/) 和 [Backtest](../owners/backtest/)。
