# 安装

安装只建立可复现的开发基础，不会激活策略、连接实盘执行适配器，也不会授予产生外部交易效果的权限。

后端与 Web Dashboard 面向服务器部署；本地工具链用于开发验证。外部 Agent 的模型配置不属于 R&D 前置条件；部署边界见[服务架构](../architecture/)。

## 前置条件

- 与当前仓库版本匹配的 Python 和 Rust 工具链。
- 用于文档站点的 Node.js。
- 只为明确选择的数据或执行适配器配置凭据。
- 用于生成策略代码和探索工作的隔离环境。

始终使用仓库当前的 Makefile 与 CI 工作流，不要复制旧文档中的历史命令。

## 凭据与配置

只配置实际启用的适配器所需凭据。Market Data 使用数据提供方支持的公开入口或获准数据凭据；交易服务仅在独立效果授权后使用交易凭据。变量存在不证明数据权利、接口能力或交易权限。

论文、文章和视频获取使用 Agent 宿主已有工具，其模型和工具配置不属于服务器安装前置；不为潜在来源列出一套待开发服务器 connector。Agent 记录来源后，R&D 保管引用和说明；行情文件仍须经过 Market Data 准入。

秘密只进入获准服务的运行环境或 ignored local secret，不提交、打印、记录或复制到请求、结果、工件和审计包。仓库 Agent 不得使用交易所交易凭据。数据许可、费用授权和 PIT 验证见[市场数据接入](./market-data-intake/)，宿主来源与产品托管入口的边界见[来源接入](./source-intake/)。

## 构建基础能力

在仓库根目录使用当前构建入口：

```bash
make build-debug
```

构建和测试通过只证明本地软件基础可复现，不证明数据适用、策略有效、资格成立、资金获批、
实盘连通或恢复安全。

## 使用数据之前

配置 Market Data 适配器，并验证标的身份、时间戳、覆盖范围、历史修订、许可和 PIT 可用时间。
事实缺失或含义不明确时，依赖它的研究、回测、扫描、估值或交易都必须停止。

## 真实试盘与正式运行之前

产品链必须具备已通过资格评估的工件、Governance 部署决定、Risk 政策、Execution 适配器、
对账和 Recovery 路径。模拟与实盘使用相同的意图、风控、订单和反馈语义，只替换执行适配器。

真实试盘和正式运行都需要独立的效果准入、当前授权与首次试盘确认。Paper 仅用于另行获准的原生模拟验证，不是晋级前置。仓库代理不得使用交易所交易凭据；安装或文档任务不授予凭据使用或下单权。
