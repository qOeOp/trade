# VibeTrading 产品设计

VibeTrading 面向一个个人用户，由一个可更换的外部 AI 代理协助量化研究。用户给出市场问题、风险容忍和资源边界，代理通过 MCP
调用数据、策略编写、回测与研究服务，把假设变成可复现策略、组合证据和明确的下一步决定。

数据与回测以本仓库的 Nautilus 为基础扩展；研究管理由自研 R&D 服务承担。自研 Dashboard 提供同一事实的
只读研究视图与获准的 Governance 控制界面。产品不内置研究模型，不要求用户用对话手工驱动内部步骤，也不把探索结果当作交易许可。

## 使用本设计

从用户故事读取需要实现的行为，再进入所属服务的具体契约；入口章节不另定义一套 schema 或拒绝语义。
章节中的目标能力是完整产品设计，`CURRENT/PARTIAL` 是已有接线范围，`TARGET` 是待开发能力，
`NOT_ADMITTED` 是尚未获得实现或效果准入。目标设计不能被当作当前可调用能力。

文档是一套可修订的设计。实现测量或用户决定改变设计时，修改所属章节并同步直接消费者，删除被替代描述；
不追加一套新规则让读者自行判断哪段有效。已有不可变业务记录与版本兼容规则按契约保留。
