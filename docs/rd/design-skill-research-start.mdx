## `SKILL.md` [#def-file-research-start-SKILL-md]

**触发**　每次开始或中断恢复研究，以及路线内判定需要换路线、回到入口时

core：先读账本（research state 的 open_lines 列出开着的路线），中断恢复续做本会话 Goal 写明的那条路线，新会话把每条开着的路线（现状与下一步）和新路线选项并列给用户，等用户选；给路线选项后以提问结束，选定前不登记不回放；模板根与人造根的触发条件；进入路线前按账本自己设宿主目标。research state 列出 RUNTIME_UNSUPPORTED 时，告诉用户这条线在产品不再运行的旧运行契约上，只能关闭、在新契约上重开，不续做、不为它设 Goal；列出 MARKET_COMMIT_UNRESOLVED 时，告诉用户缺的是哪个市场提交、它回到市场库之前这条线不能登记也不能重放；恢复它是用户的数据决定（写市场库），不是研究步骤，提问只给能马上跑的路线，不把保留、暂停或等这条线直到提交取回、恢复或核验当选项，不自己提议接回历史、改解析器或写市场库，不为这条线设 Goal，用户选别的路线代替它时以 line close 显式关闭它，只是另开一条时它继续开着；没有一条现有路线能跑时列模板根；在新契约上重开以根开始（发布不带父，登记无父、无对照、changed_duties 为空，理由带旧候选的思路），旧契约候选不作父或对照；以旧契约候选为基础的重开选项向用户写明三点：重开是新规则而非旧规则再跑、首报没有对照、旧规则的结果不能再检验。用户选定后先核就绪；新根先发布、预检并经审查，再用 line select 记新路线，--start 是审查通过的那一版；选已开的路线不再 line select，它已有记录；用户为这条路线给了两个研究目标（最大回撤与最低年化）时以 --max-drawdown、--annual-return 同时写入，否则路线取账本默认值，两者都没有就问用户；用户之后改目标用 line targets --line 记，Agent 不自己改；关线在用户说结束、路线因 RUNTIME_UNSUPPORTED 等门槛无法继续、或到了换线时用户选了别的路线时做：先读 research state --line 写这条路线的总结，再执行 line close；用户只是另开一条路线时，原路线继续开着；之后从 research state 返回的 targets 取生效的两个目标（路线自己的，否则账本默认值）。路线内的输入检查只返回就绪报告，保留原路线与授权，不重新选线或启动 Goal。另列三个 references 文件各自何时读

## `references/readiness.md` [#def-file-research-start-references-readiness-md]

**触发**　首次回放前核就绪、覆盖回执出现缺口、零量或资金费缺失、新月份数据到达，或推算报价用于新合约、时段、强平情景时

回放前核镜像、月份与逐合约覆盖并报精确阻断与可运行范围；路线或会话的首次回放前另核检出：HEAD 是 origin/main 上的提交且工作树干净（封存把检出提交记为读数的版本），否则不登记不回放，把提交与未提交路径告诉用户；缺口记事实不判经济失败；新月份只报可扩展范围，由用户选窗口。覆盖事实用 market coverage 读，输出见其 --help

覆盖异常的报告要求同时适用于首次回放前和已完成回放后。最终回答分别给出：三类事实与未证原因、按原市场提交逐合约逐区间的可运行范围及阻断、保留的路线／候选／登记或运行状态。只在会阻断或扭曲回放的异常上（见下方 W.3.3.2 所列情形），最后直接请用户选择补核来源证据并保留范围，还是经核对后由用户选其他受支持的数据范围；否则报告上述内容后继续，不提问。

仅知道一个缺口时，缺口外区间只能说未被该缺口阻断，不能据此证明其他覆盖；资金费具体时刻或回执不明时，明确哪段范围尚未确定以及缺什么证据，不把零成交量变成缺 K 线，也不自动排除整月。不把“要不要写记录／先查哪项”当作数据与范围选择，不代用户删币、缩窗、补数或换提交。

低活跃度合约是否适用于强平研究，按具体合约、UTC 时段和实际使用场景（杠杆、敞口与强平情景）验证，并标明市场提交、报价规则和运行镜像。推算报价的买卖两侧各自沿用旧值，成交稀疏时可能陈旧；误差可使强平提前或延后。一分钟决策、数据覆盖完整、原生回放通过，均不能证明分钟内报价适用。

取证前先写出它能改变哪个决定（执行环境、窗口、合约或某项强平结论）以及什么结果算够；结果改变不了任何决定的证据不取。适用性按源码设计的强平距离对推算报价的实测误差判断：距离远大于误差时报告限制并继续；只在决策变量接近阈值的区间才查参考源自身的缺口或跑配对回放。

成交间隔、活跃分钟和过时侧调整次数只作诊断，不等于逐侧报价年龄，也不设未经校准的准入阈值。应在有独立真实买卖报价的范围内核对来源、时间语义、覆盖及误差分布，并在策略、配置和镜像相同、只替换报价输入的原生回放中比较强平是否发生、时刻、价格和账户结果；样本内未强平不证明其他情景。原件、报告与比较放 /tmp；读数连同来源身份（URL、校验和、覆盖、对齐规则、市场提交与报价规则）用 <code>evidence add</code> 记成证据包，供之后的会话在已证范围内复用；公开归档凭校验和可重取的原件、条款禁止再分发的原件不存。

BTC 或少数日期的结果不外推到其他合约、时段或用途。缺适用性证据只限制强平结论，不挡回放：逐项报告未验证范围、实际核对了什么及受限的强平结论，用证据支持的结论继续，区分“技术上可运行”和“已有适用性证据”；不自动删币、缩窗、更换输入或调整产品指标资格，不补造或过期替换报价。某一步的结果改变不了处置时，一句说明并把数据/范围或设计选择交还用户；不提供取不到的“补证据”选项。

评测 <code>inferred-quotes-scope-evidence</code> 检查 BTC 抽样、稀疏成交和原生通过不能外推为全窗口强平适用；<code>inferred-quotes-matched-scope</code> 检查已有同范围证据时不因低活跃度一刀切禁用或重复索权；<code>quote-evidence-limits-claims-only</code> 检查报价齐全、强平距离远大于实测误差且再无可取的独立盘口时，照常回放、写明受限的强平结论，不挡回放、不提议继续找数据或缩窗。

## `references/recommendation.md` [#def-file-research-start-references-recommendation-md]

**触发**　入口要呈现最新推荐与路线选项时

先读本路线（--line）研究状态的最新推荐，无推荐或有未复盘有效运行时现算追加；每个选项列全多维指标，算不出的留空写原因；推荐写明版本、依据、取舍及与下一父版本的区别；列出或推荐一条线前确认起点能在所选窗口登记、市场库覆盖所需月份（在要钉住的提交上用 market coverage 核对；要钉的提交是 line select 的缺省、市场 head，除非用户指定），已运行过的源码不能在新窗口再登记研究，冻结规则再检验只走用户发起的样本外验证（窗口在验证登记之后，不用更早的月份）；不合的选项不列，一句话说明原因；缺月份的线不作为可开始的选项，告诉用户缺哪些月份、导入是另一步且会写入公开的市场库

<li id="def-rule-E-3-1-1">入口先读研究状态的最新推荐；无推荐或有未复盘有效运行时现算并追加 <span className="rd-rule-links"><Ref id="E.3.1.1">E.3.1.1</Ref></span><span className="rd-eval">eval <code>unreviewed-trials-from-commit-diff</code>：上次推荐之后新增若干试验时，按 research state 的 unreviewed_trials 先复盘、写新推荐，再给路线选项，不因产品的复盘停点还没到就沿用旧推荐；不重读整个账本手工比对，也不写补记</span></li>
