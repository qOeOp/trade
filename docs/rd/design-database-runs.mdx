# Runs and sealed readings

Execution validity, audits, fingerprints, sealed reports, daily returns and native position cycles have distinct records.

[Database overview](/en/docs/design-ledger/)

### `run` [#def-table-run]

运行：一次研究或样本外封存回放的结论、审计发现、单运行报告与原生报告指纹；执行身份不在此重复，按试验与登记包读

<TypeTable type={{ "trial_id": { type: "INT", description: "执行前已生成的试验编号，同时为结果主键与外键", required: true }, "status": { type: "ENUM('passed','invalid')", description: "审计结论", required: true }, "failure_reasons": { type: "JSON", description: "无效原因，只引用审计发现的编号；通过为空", required: false }, "audit": { type: "JSON", description: "{ran, findings}：审计是否跑完与发现清单；审计边界属审计器版本，不存", required: true }, "fingerprints": { type: "JSON", description: "原生报告的语义指纹：由该运行镜像内的指纹入口计算，覆盖订单、成交、持仓、账户、日收益、订单事件与敞口；每表行数、整表哈希与逐 UTC 日哈希；逐字节稳定的账户、日收益、敞口另记字节哈希；通过的运行必有，无效运行为空", required: false }, "op_id": { type: "VARCHAR(160)", description: "幂等操作 ID", required: true }, "created_at": { type: "DATETIME(6)", description: "服务器入账时间", required: true } }} />

**键与约束**

- 主键　`trial_id`
- 唯一　`op_id`
- 外键　`trial_id` → <Ref id="table:trial">trial</Ref> `trial_id`
- CHECK　`(status = 'invalid' AND failure_reasons IS NOT NULL) OR (status = 'passed' AND failure_reasons IS NULL)`
- CHECK　`(status = 'passed' AND fingerprints IS NOT NULL) OR (status = 'invalid' AND fingerprints IS NULL)`

**Dolt 能力**

- **J.3.2.1**　与封存结果、逐日序列、持仓周期同一事务恰一个 DOLT_COMMIT
- **J.3.2.2**　共享主键 trial_id 加固定 op_id：幂等，第二次写入返回原记录
- **J.3.1.1**　dolt_diff_run 定位任何被改绩效指标，非 added 即篡改发现
- **J.3.1.3**　AS OF 重算当时绩效指标
- **D.1.2.2**　绩效指标列与 status 从不改写；重评与更正只作新证据包，旧版本 AS OF 可读
- **J.5.4.1**　运行环境身份列随行永久可读回，旧镜像按摘要仍可拉取
- **J.3.5.1**　不运行 DOLT_GC；随 dolt_backup 全史备份
