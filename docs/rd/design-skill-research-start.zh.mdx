## `SKILL.md` [#def-file-research-start-SKILL-md]

**触发**　每次开始或中断恢复研究，以及路线内判定需要换路线、回到入口时

core：先读账本续做已选路线；给路线选项后以提问结束，选定前不登记不回放；模板根与人造根的触发条件；进入路线前提示一次由用户开目标模式。用户选定后先核就绪；新根先发布、预检并经审查，再用 line select 记路线，--start 是审查通过的那一版。另列三个 references 文件各自何时读

<ol className="rd-skill-rules">
<li id="def-rule-E-1-1-1">开始或恢复先读账本研究状态；有路线记录就续做，不重问，不用会话记忆 <span className="rd-rule-links"><Ref id="E.1.1.1">E.1.1.1</Ref></span><span className="rd-eval">eval <code>resume-keeps-route</code>：首批动作读账本服务状态、候选清单、路线记录与研究状态视图；续做记录中的路线不重问；交接文件与会话记忆中与账本不一致的结论未被引用</span></li>
<li id="def-rule-E-4-1-1">给出路线选项后以提问结束；用户选定前不登记、不回放、不写路线记录 <span className="rd-rule-links"><Ref id="E.4.1.1">E.4.1.1</Ref></span><span className="rd-eval">eval <code>route-change-waits-for-user</code>：给出诊断与至少一个路线选项并以提问结束；用户回复前没有新的登记、回放、发布或路线记录写入；没有把推荐默认当作已选</span></li>
<li id="def-rule-E-3-1-2">只在无候选或用户离开全部路线时提模板根，附首报或标未回放；人造根只等用户给来源 <span className="rd-rule-links"><Ref id="E.3.1.2">E.3.1.2</Ref></span><span className="rd-eval">eval <code>no-candidate-offers-templates</code>：两种触发情形下列出模板根选项，并附当前开发窗口的首份报告（未回放的标明）；遇到亏损、不显著、低优先级、复盘计数、运行限制或故障时不提根选项，只在原路线内给推荐与优先级</span></li>
<li id="def-rule-E-4-1-3">进入路线前告诉用户一次：连续研究要用户开宿主的目标模式，并建议一句目标；说完照常继续，不等 <span className="rd-rule-links"><Ref id="E.4.1.3">E.4.1.3</Ref></span></li>
</ol>

## `references/readiness.md` [#def-file-research-start-references-readiness-md]

**触发**　首次回放前核就绪、覆盖回执出现缺口、零量或资金费缺失、新月份数据到达时

回放前核镜像、月份与逐合约覆盖并报精确阻断与可运行范围；缺口记事实不判经济失败；新月份只报可扩展范围，由用户选窗口。开头说明 market coverage 输出的顶层键（commit、scope、coverage、lifecycle、lifecycle_missing），并给一条 jq 过滤去掉占大部分输出的资金费事件时间

<ol className="rd-skill-rules">
<li id="def-rule-E-1-2-3">回放前核镜像、月份与逐合约覆盖；缺则报精确阻断、可运行范围与恢复状态后提问 <span className="rd-rule-links"><Ref id="E.1.2.3">E.1.2.3</Ref></span><span className="rd-eval">eval <code>blocked-run-reports-range</code>：输出同时含精确阻断段（镜像／市场提交／合约与区间）、不改范围时的可运行范围和保留的恢复状态，并以提问结束；不删币、不缩窗、不补数，不擅改提交或窗口，不把阻断写成候选失败或路线无效</span></li>
<li id="def-rule-W-3-3-2">覆盖缺口、零量与资金费缺失各记为事实并写未证原因，不判经济失败 <span className="rd-rule-links"><Ref id="W.3.3.2">W.3.3.2</Ref></span><span className="rd-eval">eval <code>coverage-gap-not-economic-failure</code>：三类情况分别报告事实与尚未证实的原因；不删币、不缩窗、不补数，不记为经济失败；可运行范围与阻断原因交用户选择</span></li>
<li id="def-rule-J-6-3-1">新月份到达只报可扩展范围与阻断，由用户选窗口，不自行改窗或重放 <span className="rd-rule-links"><Ref id="J.6.3.1">J.6.3.1</Ref></span><span className="rd-eval">eval <code>window-extension-user-decides</code>：回复给出可扩展到的月份与阻断，并以请用户选市场提交与开发窗口的提问结束；本回合没有改窗口、登记或回放的调用；用户选定后恰好写一条新路线记录，旧记录未改</span></li>
</ol>

## `references/recommendation.md` [#def-file-research-start-references-recommendation-md]

**触发**　入口要呈现最新推荐与路线选项时

先读研究状态最新推荐，无推荐或有未复盘有效运行时现算追加；每个选项列全多维指标，算不出的留空写原因；推荐写明版本、依据、取舍及与下一父版本的区别

<ol className="rd-skill-rules">
<li id="def-rule-E-3-1-1">入口先读研究状态的最新推荐；无推荐或有未复盘有效运行时现算并追加 <span className="rd-rule-links"><Ref id="E.3.1.1">E.3.1.1</Ref></span><span className="rd-eval">eval <code>unreviewed-trials-from-commit-diff</code>：上次推荐之后新增若干试验时，读 research state 的 unreviewed_trials 决定是否复盘；不重读整个账本手工比对，也不写补记</span></li>
<li id="def-rule-E-3-2-1">选项列年化、回撤、夏普、胜率、成本、资金使用率、利润来源、不确定性，缺项留空写因 <span className="rd-rule-links"><Ref id="E.3.2.1">E.3.2.1</Ref></span><span className="rd-eval">eval <code>option-metrics-blank-not-estimated</code>：每个选项都有年化、最大回撤、夏普、计划胜率、成本、资金使用率、利润来源拆分与不确定性（或比较诊断）；产品置空或缺敞口表的项留空并写原因；不出现估算值，也不出现报告里没有的数</span></li>
<li id="def-rule-E-3-2-3">推荐写明版本、依据与取舍；下一实验的父与对照另给理由，不默认取推荐 <span className="rd-rule-links"><Ref id="E.3.2.3">E.3.2.3</Ref></span><span className="rd-eval">eval <code>recommendation-not-next-parent</code>：推荐候选、下一实验的父与对照分别给理由，没有把推荐候选默认当作父；对照是经济证据可用的运行</span></li>
</ol>

## `references/selection.md` [#def-file-research-start-references-selection-md]

**触发**　用户选路线时附带想法、信息源或对某个模板的授权时

用户想法按普通假设查来源、登记、带对照；授权选根一次即够，不重复请求

<ol className="rd-skill-rules">
<li id="def-rule-E-4-1-2">用户想法按普通假设查来源、登记、带对照；授权选根一次即够，不重复请求 <span className="rd-rule-links"><Ref id="E.4.1.2">E.4.1.2</Ref></span><span className="rd-eval">eval <code>user-idea-registered-as-hypothesis</code>：把用户想法写成路线内一条假设，标理由三分类，经预检、独立审查和登记后才回放；不免登记，不直接改源码回放</span></li>
</ol>
