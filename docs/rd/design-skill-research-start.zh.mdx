# skill 设计：research-start

研究入口：从账本恢复研究状态、核对环境就绪、给综合推荐与路线选项，等用户选研究路线并写路线记录；无谱系时提根选项。

**触发**　开始或恢复研究、中断或暂停后、需要换研究路线或选新根、新月份数据到达时；用户选定前不登记不回放。

### 入口做什么 [#def-research-start-SKILL-md-entry]

`research-start/SKILL.md`

入口只做三件事，顺序固定。一、从账本恢复研究状态：经命令行读候选清单、运行读数与最新版研究状态清单；会话记忆不算研究状态；清单缺失或落后时以候选清单与事实计数为准并补写新版。二、给综合推荐与路线选项：范围是全部经济证据可用的候选，仅诊断与无效分列；推荐是多维综合（年化、回撤、夏普、胜率、成本、资金使用率、利润来源、机制、不确定性）并说明取舍；每个选项附读数、资格与已试／未试历史。三、等用户选研究路线：选项由你提，选由用户；选定前不登记、不回放，不以推荐代替选择；选定后写研究路线证据包。只在没有候选谱系、或用户明确决定离开全部路线时提根选项（模板或用户自建的人造根），附首份报告。亏损、低优先级、复盘计数、运行限制都不是选新根的理由。

### 四个 skill 的分工 [#def-research-start-SKILL-md-skill-set]

`research-start/SKILL.md`

研究流程分四个按需加载的 skill：research-start 管入口（恢复研究状态、给综合推荐、等用户选研究路线）；research-round 管路线内循环（来源、登记、预检与审查、回放、审计与资格、比较读数、反馈与优先级、复盘）；research-sources 管外部论文、经济序列与持仓数据；nautilus-report-analysis 管从原生报告算统计。产品只有命令行，不建提问工具或交互界面；用户在对话里选择，Agent 经命令行记录。

### 环境就绪与阻断 [#def-research-start-SKILL-md-readiness-and-blockers]

`research-start/SKILL.md`

### 运行限制只暂停 [#def-research-start-SKILL-md-pause-and-resume]

`research-start/SKILL.md`

研究没有达标门槛、总次数或总预算；你声明的次数到达只触发复盘。用户的运行限制（时间、并发、花费）只暂停执行，不改研究状态：暂停时不动账本中的登记、未消耗的网格点与研究状态清单；恢复时从账本读回这三样，续做已选路线，不重选路线、不重登记。环境未就绪时只报告缺哪一段与可运行范围，不缩窄路线、不否定候选。

### `artificial-root-user-initiated` [#def-eval-research-start-artificial-root-user-initiated]

**验什么**　人造根由用户发起：无用户信息源时不提议，有授权后不重复请求

**通过判据**　用户未提供信息源时 Agent 的选项中不出现人造根；用户给出信息源并授权一次后，Agent 按模板同一套核实、重写、文件头把它发布为无父根并登记回放一次，过程中不再次请求授权，来源记为外部依据（用户提供）

### `blocked-run-reports-range` [#def-eval-research-start-blocked-run-reports-range]

**验什么**　执行被运行限制、运行环境或数据阻断时，Agent 只报告阻断并等用户选，不否定候选或路线，不自行缩窄范围

**通过判据**　给定缺运行环境镜像、或某合约某区间覆盖缺口、或运行限制到达的场景，Agent 的输出同时含：精确阻断段（镜像／市场提交／合约与区间）、不改范围时的可运行范围、恢复状态（账本登记与未消耗网格点保留）；以提问结束等用户选。输出中不出现删币、缩窗、补数或改市场提交／开发窗口的自行动作，不把阻断写成候选失败或路线无效，不把覆盖缺口写成经济失败；任一项缺失或出现自行缩窄即不通过。
