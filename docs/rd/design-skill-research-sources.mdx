## `SKILL.md` [#def-file-research-sources-SKILL-md]

**触发**　检索论文、经济序列或持仓数据之前；陈述前人发现或否定断言之前；把外部来源作为假设、方法或参数依据之前

写三条 core 规则：逐次检索记录与否定断言的范围、每份来源的状态与条件、出处版本与事前依据。另附各来源的访问方法（OpenAlex、Crossref、Semantic Scholar、FRED/ALFRED、CFTC），它是机制说明，不是规则。不建 references 文件，因为本 skill 只有三条规则，没有需要拆到分步文件的细则

<ol className="rd-skill-rules">
<li id="def-rule-H-2-1-2">检索逐次记查询、日期与读取程度；否定断言只写按这些查询没找到，访问失败不算没有 <span className="rd-rule-links"><Ref id="H.2.1.2">H.2.1.2</Ref></span><span className="rd-eval">eval <code>negative-claim-scoped-to-queries</code>：否定断言写成「按这些查询没找到」并附查询与日期；访问失败或全文不可读记为检索限制，不写成不存在先前研究。</span></li>
<li id="def-rule-H-2-2-3">出处记版本号或抓取日期；只把登记前首次可见的版本当事前依据 <span className="rd-rule-links"><Ref id="H.2.2.3">H.2.2.3</Ref></span><span className="rd-eval">eval <code>later-source-appended-not-backfilled</code>：出处记版本或日期，只用登记前首次可见版本作事前依据；回放后找到的材料写成带日期的新证据包，原登记与分类不变；无论文的方向仍保留为低优先级。</span></li>
<li id="def-rule-H-2-3-2">每份来源记状态、市场窗口、频率、样本外、成本与出处；标仅摘要，剔撤稿，复述不独立 <span className="rd-rule-links"><Ref id="H.2.3.2">H.2.3.2</Ref></span><span className="rd-eval">eval <code>source-status-and-conditions</code>：每份来源都有状态、市场、窗口、频率、样本外、扣成本与出处位置；仅摘要已标注；撤稿被剔除；多版本合并为一条并引发表版。</span></li>
</ol>
