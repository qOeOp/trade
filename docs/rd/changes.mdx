## D.1　认定变化：什么算变了，旧记录怎么留 [#D-1]

<Steps>

<Step>

导入新月份或回放时，代码自动记下新的执行身份。

</Step>

<Step>

新月份到达只报可扩展范围；用户选定窗口后，写成新的研究路线。

</Step>

<Step>

按当前执行身份，从账本只读查出受影响的运行、登记和判断记录。

</Step>

<Step>

旧记录原样保留并可读回，读回时按当前检查重判资格；评价变了，只追加新证据包或判断记录。

</Step>

<Step>

在新执行身份下另行登记，再回放。

</Step>

</Steps>

### D.1.1　变化的种类 [#D-1-1]

交易所数据和运行环境的变化由代码自动区分，开发窗口扩展由用户选。

<li id="D-1-1-3"><span className="rd-rule-id">D.1.1.3</span> 新月份只报可扩展范围和受阻原因，窗口由用户选 <Ref id="rule:D.1.1.3">research-start · references/readiness.md</Ref></li>
</ul>

## D.2　恢复可比性：在新环境下重放对照和候选 [#D-2]

<Steps>

<Step>

Agent 按变化的执行身份查出受影响运行，并读取当前研究状态。

</Step>

<Step>

排出重放范围和顺序，写成一条研究优先级判断记录。

</Step>

<Step>

在新执行身份下先重放对照、再重放候选，得出检验结果。

</Step>

<Step>

只按新身份下的可比证据追加综合推荐，并告诉用户。

</Step>

</Steps>

### D.2.2　重放范围和结果呈现 [#D-2-2]

从受影响运行和研究状态出发，定下重放优先级和新的综合推荐。

<ul className="rd-rules">
<li id="D-2-2-2"><span className="rd-rule-id">D.2.2.2</span> 执行身份变了，先重放当前推荐候选和它的对照，只凭新的可比证据推荐 <Ref id="rule:D.2.2.2">research-round · references/changes.md</Ref></li>
</ul>

## D.3　运行环境变更：先用配对重放证明引擎行为没变 [#D-3]

<Steps>

<Step>

固定同一份源码、输入数据、窗口和账户，在旧、新运行环境各回放一次。

</Step>

<Step>

逐条比较两份原生报告，判定引擎行为是否一致。

</Step>

<Step>

一致：结论只限于这组配对下引擎行为未变，新比较证据按 D.2 产生。

</Step>

<Step>

不一致或有意改变引擎行为：旧运行留作历史证据，受影响运行交给 D.2 重放。

</Step>

<Step>

旧源码要适配新环境时，以旧候选为父版本派生新候选，预检和审查通过后登记重放。

</Step>

</Steps>

### D.3.1　旧、新运行环境配对重放 [#D-3-1]

同一源码、输入、窗口和账户在两个运行环境各跑一次，由代码比对两份原生报告。

<Cap id="D.3.1.2" kind="code" tier="verified" tierLabel="已验证" title="两份原生报告逐项一致，才算引擎行为没变">

- 订单、成交、持仓、账户、日收益五张报表，除引擎随机编号列外逐字段相等。
- 资金费调整逐条相等，不留容差；账户汇总指标在小容差内相等。
- 程序正常退出、报告能读或测试通过，都不算一致。
- 比较只读、不写账本，也不产生绩效指标。

### D.3.2　有意变更或证明不了时 [#D-3-2]

旧身份下的记录永久可读回；受影响运行只读查出后，交给 D.2 重放。

<Cap id="D.3.2.1" kind="code" tier="rehearsal" tierLabel="演练证据" title="有意变更或配对不一致时，旧运行原样保留、永远可读回">

- 适用于有意改变引擎行为，或配对重放不一致、无法进行时。
- 旧运行、绩效指标和比较证据原样保留，作为旧身份下的历史证据。
- 旧运行环境按摘要保留，读回时仍能核对；删除它须用户授权。
- 受影响范围按新身份只读查出，不排序，也不打标记。

## 待定事项 [#D-pending]

**待用户定**

- **上游交易所公布历史数据修正时怎么办**　市场库只追加，改写已存月份或来源冲突即拒绝（POOL_CHANGED／SOURCE_CONFLICT），历史修正进不来；是否另立市场库身份承接修正待用户定。

- **不进文档**　数据或环境变化后是否重跑进行中的样本外验证：样本外登记绑定输入身份与窗口、一登记一回放；能否再登记由 <Ref id="X.1.3.1" /> 与凭证时间决定，D 不另立；已完成的样本外验证不重跑。
- **不进文档**　变化后的候选能否作为推荐范围或父版本：所有候选按经济证据资格进入推荐范围与父版本选择，变化只改变可比性与研究优先级，不产生存疑标记。
- **不进文档**　新旧窗口试验相关性按重叠日期算：试验相关性的计法归试验次数折扣（<Ref id="R.4.2.2" />）；D 只规定历史试验仍计入研究计数（<Ref id="H.4.2.1" />），按开发窗口分列。
