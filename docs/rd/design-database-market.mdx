# Market data and universe

Contract specifications, last and mark bars, inferred bid/ask quotes, funding and monthly universe membership belong to the market database.

[Database overview](/en/docs/design-ledger/)

### `instrument` [#def-table-instrument]

合约条款按观测时刻追加：精度步长与限额取自交易所公开条款原文，已下架合约从成交推断步长；导出按市场提交取最新一行

**键与约束**

- 主键　`symbol`, `observed_at`
- CHECK　`(terms_source = 'inferred') = (min_quantity IS NULL AND max_quantity IS NULL AND min_notional IS NULL AND min_price IS NULL AND max_price IS NULL AND classification IS NULL)`

**Dolt 能力**

- **W.1.3.2**　一次导入全部追加后恰一个 DOLT_COMMIT：提交哈希即数据版本 market commit
- **W.1.3.2**　AS OF '\<market_commit>' 导出：任何时候逐字节复现某次回放读到的条款
- **D.1.1.1**　dolt_diff_instrument 只应出现 added；出现 modified/removed 即条款被改写
- **W.4.2.2**　导出取 AS OF market_commit 下 observed_at 最新一行，回执记 CURRENT_SNAPSHOT_APPROXIMATION

### `bar` [#def-table-bar]

1 分钟 K 线：成交价 LAST 与标记价 MARK（无量）；每个永续独立序列，三来源拼成一条、来源不留痕；缺口即缺行，不补造

<TypeTable type={{ "symbol": { type: "VARCHAR(40)", description: "交易所公开合约名", required: true }, "price_type": { type: "ENUM('LAST','MARK')", description: "成交价或标记价", required: true }, "ts_open": { type: "BIGINT", description: "开盘时刻 UTC 毫秒，整分钟；导出时以收盘时刻为事件时间", required: true }, "open": { type: "BIGINT", description: "× 10^price_scale", required: true }, "high": { type: "BIGINT", description: "× 10^price_scale", required: true }, "low": { type: "BIGINT", description: "× 10^price_scale", required: true }, "close": { type: "BIGINT", description: "× 10^price_scale", required: true }, "volume": { type: "BIGINT", description: "× 10^volume_scale；MARK 恒 0", required: true } }} />

**键与约束**

- CHECK　`price_type = 'LAST' OR volume = 0`

**Dolt 能力**

- **W.1.3.2**　一次导入全部追加后恰一个 DOLT_COMMIT：提交哈希即数据版本 market commit
- **W.1.3.2**　AS OF '\<market_commit>' 导出：任何时候逐字节复现某次回放读到的 K 线
- **D.1.1.1**　dolt_diff_bar 只应出现 added；出现 modified/removed 即数据被改写
- **W.1.1.2**　同一分钟两来源不等即整次导入拒绝，不以一方覆盖另一方

### `quote` [#def-table-quote]

保存声明规则从 aggTrades 推算的完整买卖价状态变化；来源是近似报价，不是逐档盘口或真实可成交深度。

<TypeTable type={{"symbol": {"type": "VARCHAR(40)", "description": "公开合约名；与同提交条款及生命周期片段对应", "required": true}, "ts": {"type": "BIGINT", "description": "产生此状态的 aggTrade transact_time，UTC 毫秒；允许同毫秒多行", "required": true}, "agg_trade_id": {"type": "BIGINT", "description": "产生此状态的成交编号；区分同毫秒状态并用于来源核对，状态变化筛选后编号不必逐行连续", "required": true}, "bid": {"type": "BIGINT", "description": "推算买价 × 10^market_schema.price_scale；不是观测盘口", "required": true}, "ask": {"type": "BIGINT", "description": "推算卖价，采用同一定标", "required": true}}} />

**键与约束**

- 主键　`symbol`, `ts`, `agg_trade_id`；读取按 `ts, agg_trade_id` 排序，同毫秒状态不合并。
- CHECK　`bid > 0 AND ask > bid`。
- 五列均为 NOT NULL。没有 bid_size／ask_size、档位、逐侧年龄或来源文件列；导出用合约 max_quantity 填两侧数量，不等于实际盘口深度。

**职责与来源**　只追加输入状态，不存订单、成交、仓位或账户。`quote_rule`、实际读取的每日归档 SHA-256（含用于续接的前日）和日诊断读数保存在对应 Dolt 提交消息，由 <Ref id="market.quote_imports" /> 读取，不复制成表字段；市场提交钉住输入版本。归档 zip 在下载缓存，不因有哈希就声称原件已存入此表或完成独立备份。

**写入方**　<Ref id="cli.market_import_quotes" /> → <Ref id="market.import_quotes" />；推算与定标分别由 <Ref id="market.derive" />、<Ref id="market.scaled_rows" /> 负责。一个月一次事务／提交；同合约同月已有报价时拒绝，历史行不覆盖。

**读取方**　<Ref id="market.quote_rows" /> 按市场提交 AS OF 流式读取，经 <Ref id="market.write_quotes" /> 写为原生 QuoteTick，<Ref id="market.export_episode" /> 把 `counts.quote`、`quote_size` 写入导出回执；报价环境由 <Ref id="engine.execution_account" /> 选择。早于该表创建的历史提交读为空流，默认 K 线导出仍可用；报价环境缺有效报价仍按现有检查拒绝。

**关联与边界**　`symbol` 在应用读取时与 instrument 条款、universe_month 成员及生命周期片段关联，DDL 没有为它新增外键。推算规则和逐合约／时段／用途的证据边界沿用 <Ref id="W.1.2.1" />，原生强平环境沿用 <Ref id="W.4.2.1" />。本页记录既有存储，不增加字段或规则。

### `universe_month` [#def-table-universe_month]

共同可交易范围 universe：环境按事前规则在每个 UTC 月初产出的成员名单，不排名、不取前 N；后来下架的合约留在当时名单里；成员时间路径由本表按 AS OF 派生

<TypeTable type={{ "universe_rule": { type: "VARCHAR(60)", description: "产出该行的范围规则版本；不同版本的名单共存，旧行不改", required: true }, "month": { type: "DATE", description: "UTC 月初", required: true }, "symbol": { type: "VARCHAR(40)", description: "成员合约的交易所公开名；ticker 重用在导出时按生命周期拆为原生合约", required: true } }} />

**键与约束**

- 主键　`universe_rule`, `month`, `symbol`
- CHECK　`DAYOFMONTH(month) = 1`

**Dolt 能力**

- **W.1.3.2**　随导入在同一提交追加；导入前重算全部月份并与已存行比对，不一致 UNIVERSE_CHANGED 拒绝，旧提交上的名单不被改写
- **D.1.1.1**　dolt_diff_universe_month 只应出现 added；AS OF 重现任一提交的成员时间路径
- **W.3.1.2**　AS OF market_commit 派生范围规则、合约清单与每合约 [start, end) 成员时间路径，进入输入身份
- **X.1.3.1**　样本外绑定时在登记的 market_commit 与本次 market_commit 下逐行比对登记前各月名单
