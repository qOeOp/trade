# 待定与待验证事项

## 待用户定

- **E** 是否允许同时推进两条用户选定的研究路线　演练中只走过单路线，研究路线记录按一次一条设计（E.4.2.1）；是否放宽由用户定
- **L** 候补名单从哪来、由谁定　可由 Agent 按 <Ref id="L.1.3.3" /> 的收录标准提候补、用户选，尚未定；<Ref id="L.1.2.1" /> 只写换下一个候补并说明原因。
- **L** 第二批多品种／双腿模板的名单与启动时点　产品允许做现货，但名单未给；<Ref id="L.1.1.2" /> 只写第二批范围：横截面动量、配对、资金费 carry。
- **L** 模板首次回放的范围（全池全开发窗口一次到位，还是先有界先导）　演练中全池回放工程成本高，多数试验被生命周期、原生身份或容量阻断；<Ref id="L.2.2.1" /> 只写回放一次，范围由用户选。
- **C** 部分成交对齐、成交时刻、按缺口补挂升格为具名审计项　升格须用户授权改动审计检查；授权前由 <Ref id="C.6.2.1">独立源码审查</Ref> 与 <Ref id="G.3.3.1">裸仓审计</Ref> 覆盖，不进代码。
- **W** 外部数据按发布时刻对齐（point-in-time）是否在本章另立一节　做法见 research-sources 的数据参考（point-in-time、ALFRED vintage）；本章暂不含，外部数据来源归第 5 章
- **W** 杠杆与保证金率归环境条款还是策略设计变量　本章写为运行器固定的环境条款（<Ref id="W.4.1.2" />、<Ref id="W.4.2.2" />）；改为设计变量需新运行环境并重跑全部候选
- **W** 预热期下单由代码拒绝还是源码自律　本章写为源码自律加原生预检与独立源码审查；改为代码拒绝属改变拒绝边界，需用户授权
- **W** 下架结算价的权威来源　交易所公告给禁新仓与结算时刻，不给结算价算法；无权威价时只供给终止时钟并要求终止前空仓（<Ref id="W.3.2.2" />）
- **G** 审计是否核验成员禁新仓后无新开仓　成员禁新仓后不开新仓属策略文件契约；加为审计项是收紧审计检查，需用户授权。引擎 PRE_CLOSE 状态是否自动拒绝非只减仓单尚未经原生试验确认。
- **R** 回撤的块自助分布　配对块自助检验只给均值与年化差的区间；回撤分布是否作报告绩效指标未定
- **R** 回测过拟合概率（PBO/CSCV）只作报告绩效指标　论文方法与开源参照实现已核实；是否进入报告未定
- **V** 非收益维度（回撤、胜率、夏普）的配对推断　夏普差可用学生化循环块自助（与 <Ref id="V.3.2.1" /> 同机制）作第二个可登记维度；回撤是路径统计量、胜率两侧计划数不等，无成熟配对设计；扩维度改拒绝边界须用户授权。
- **F** 诊断判据看绝对绩效指标还是配对差　建议默认：部件判据读候选自身绝对绩效指标（R 口径，注明总体）；相对比较对照的改善只读检验结果（V 口径）；两者并列不混用
- **F** 三篇 Agent 自评预印本是否够格作依据　<Ref id="F.3.1.1" /> 的依据按演练证据写，不引这些预印本；用户认可后再补
- **X** 回溯窗口（开发暴露外的历史时段、同期其他标的）能否登记为降级的样本外　只认凭证之后开始的窗口，已存在数据只作探索或反驳（<Ref id="X.2.2.2" />）；若允许降级登记，需另立准入规则与分级用语。
- **X** 独立复读是否在本章留一句　绩效指标由代码算，通则见 <Ref id="R.1.2.3" />；若用户要求，在 <Ref id="X.2.1.4" /> 加一句：样本外结论段由干净上下文的第二个 Agent 复读报告。
- **X** 数据被修正或运行环境变更后，进行中的样本外登记怎么办　窗口数据已存在就不能再登记；修正数据只按 retry_of 重试使用；运行环境或账户条款不一致即拒绝绑定。是否作废登记、如何记录归 D 章。
- **J** 账本内 Dolt branch 与 tag 的组织，及写账号的 branch 授权范围　单一固定研究 branch，还是按市场或开发窗口分 branch；<Ref id="J.3.3.1" /> 按单一固定研究 branch 写
- **J** 公共时间戳凭证（RFC 3161）是否保留　删去则 <Ref id="J.4" /> 只剩服务器时间，样本外窗口准入失去外部先后证明；<Ref id="J.4.2.2" /> 按保留写
- **J** AGENTS.md 与 research/records/README.md 入账清单中样本外条目的英文用词　拟统一为 out-of-sample validations；<Ref id="J.1.1.1" /> 引用该清单，用词随用户定
- **J** 研究路线记录的载体：固定命名证据包 research-line.json 还是独立表　<Ref id="J.2.1.2" /> 按证据包写；改为表须先按 AGENTS.md 做独立字段评审并记入 docs/plans/
- **J** 是否让 Agent 的读账号只能调用读取命令、不能直接执行 SQL　这样遮蔽才是硬约束；属于收紧检查，须先在 Dolt 2.4.2 上确认权限能力。
- **A** 『每条规则须能在账本审计或案例重放中观察到，观察不到就删』是否作为 skill 规则　仍属用户偏好；A.4.3.2 只写 skill 靠 eval 与独立前向检查验证；演练中未按此判据删过规则
