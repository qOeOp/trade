# 读取入口与研究史

研究账本第 1 代没有 SQL 视图。读取都经命令行的读命令，它们用读账号钉住一个版本（`--at`，默认头提交），直接读底表并在代码里算资格、遮蔽和读数；读命令从不写入，也不发布。

[数据库总览](/zh/docs/design-ledger/)

## 读命令

| 命令 | 读什么 |
|---|---|
| `research status` | 开着的线（或 `--line`）的试验计数、研究尝试及结局、样本外登记状态、未核验的运行，以及该线的比较表：开发期、执行身份、各运行的度量、折扣夏普与支配关系 |
| `research state` | 一条线当前的研究状态：执行身份、目标、推荐与优先级、`review_every` 和未分出差异的运行（`undistinguished_runs`）、解读、未审查的试验和各项停点 |
| `research runs` | 运行列表与各自的读数 |
| `research history` | 关线历史回测的读数与判定（见下一节） |
| `research graph` | 研究图谱的谱系与运行 |
| `line list` | 开着的线；`--all` 连同已关的线 |
| `candidate show` / `list` / `export` | 候选与源码 |
| `hypothesis compare` | 一次研究登记的配对比较 |
| `validation report` | 样本外登记的结果 |
| `replay report` | 一个封存运行（状态、审计与读数）、一次预检或一个回放目录的报告 |
| `ledger sql` | 只读 SQL：一条 SELECT、SHOW、DESCRIBE、EXPLAIN、WITH、TABLE 或 VALUES 语句；写语句拒绝（`WRITE_VIA_SQL`）。报告的遮蔽不是数据访问隔离：账本是公开的 |

读的规则：

- **读命令默认只看开着的线。** 已关的线只经关线记录和关线历史回测出现，需要时按线查。
- **跨线只读汇总。** 多重检验次数、关线热力图这类跨线的数用 SQL 聚合算，不逐个加载运行。"不合格"是从读数推导的状态，不存标记。
- 复现历史结果按当时的账本提交读（`--at`），用当时的代码重放原生报告，按 `run.fingerprints` 核对。

### 研究史与关线历史回测 [#research-history-views]

研究线开着时，交易窗口只在开发期内（[研究线](/zh/docs/design-database-judgments/#def-table-research_line)）。开线时按规则固定三段：开发期（标准 12 个季度）、紧随其后的保留期（8 个季度，截至 Q）、开发期之前的历史。线开着时只用开发期；保留期、更早的历史和 Q 之后的前向段都只在关线时回放一次。

`line history` 让这条线上每个有通过研究运行的候选，用它最近一次这样的运行的源码、镜像和配置，换窗口回放：

| 段 | 窗口 | 用途 |
|---|---|---|
| veto（否决） | 开发期之前的每个日历年，各一次 | 看候选在更早的年份是否成立 |
| control（对照） | 开发期本身再跑一次 | 必须复现原来的研究运行，否则这一行不判定 |
| holdout（保留期） | 开发期之后的两年，一次 | 线开着时从未用过的数据 |
| forward（前向） | 保留期之后到市场最新完整日 | 只展示 |

每段写一个用途为 `history` 的试验和它的运行；已有运行的段跳过，所以重跑就是续跑。候选在第一次历史试验时固定。每段都有运行之后，`line close` 才能关线（否则 `HISTORY_INCOMPLETE`）。

`research history` 读出每个候选每段的度量（年化、标记价最大回撤、夏普、周期数、计划胜率）并按用户的两项目标判定：

- **否决段通过**：每个完整的否决年回撤都不超过目标，且这些年的年化中位数不低于目标；
- **保留期通过**：回撤不超过目标，且年化不低于目标；
- **达标**（`meets_targets`）：两者都通过；没有可计的完整否决年时只看保留期（`judged_on` 写明读了什么）。

这是证伪检验，不是样本外验证：按它挑候选，是在 `participants` 这些候选之中做选择，选择效应要算进去。样本外验证是用户另行发起的一次性检验（[样本外登记](/zh/docs/design-database-validation/)）。

**写入方**　`line history`（`ledger.lines.history_plan`、`ledger.trials.open_trial`，用途 history）；`line close`（`ledger.lines.close_line`）

**读取方**　`report.history`（`research history`）
