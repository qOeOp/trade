# skill 设计：research-round

<p className="rd-translation-note">English translation pending: this page shows the Chinese source text.</p>


用户选定路线内的候选研究循环：查来源、写五样并登记锁定、预检与独立审查、按网格回放、读资格与比较读数、写反馈与研究优先级、复盘与推荐；样本外验证与环境变化后的重放也在此。

**触发**　为研究问题回放前、提下一假设或选下一小批前、读任何运行的反馈前、复盘或给推荐前、宣称改善或失败前、用户发起样本外验证时、数据或运行环境变化后。

`research-round/SKILL.md`

`research-round/SKILL.md`

### 路线内一次迭代 [#def-research-round-SKILL-md-continuous-research]

`research-round/SKILL.md`

在用户选定的路线内按固定顺序推进，不在步骤之间请用户批准：查来源（先取留存且仍适用的资料，再按 research-sources 补检）→写假设五样（经济理由、来源证据、一个比较维度、网格、适用条件）并选父与对照→发布候选→原生预检（purpose=precheck）与独立 Agent 源码审查，失败即修复重发布重预检→登记并锁定网格点→每个网格点回放一次（purpose=research）→读完整性审计与实质活动资格，不通过只诊断、不记亏损→读比较证据（效应、区间、p），比较不裁决→写反馈并更新研究优先级，低优先级保留重评。改网格、源码或意图即新登记；重试另登记 retry_of。经济反馈只在资格通过后给。

### eval 的形式 [#def-research-round-evals-README-md-conventions]

`research-round/evals/README.md`

### 重放后更新推荐 [#def-research-round-references-changes-md-update-recommendation]
