# Paper 库

Paper 运行是执行记录，不是研究：存在独立的 Paper 库里，从不进研究账本，不发布，也不增加试验计数和暴露。本机和远程主机都用自己的 Paper 库。

[数据库总览](/zh/docs/design-ledger/)

Paper 库由 `ledger init` 为声明持有 `paper` 的 profile 建立（模式见 `ledger/paper.sql`，代数为 `PAPER_SCHEMA_VERSION`）。它也有 `ledger_schema` 和 `ledger_head` 两张单行表，含义同研究账本（[模式版本与写入协调](/zh/docs/design-database-coordination/)）。写账号有 SELECT、INSERT 和 DELETE（`paper delete` 删除一个已封存的运行），对 `ledger_head` 另有 UPDATE；时间由服务器触发器写，内容哈希是生成列。

Paper 运行不是研究试验：不进试验计数，不算对样本外的暴露，原生报告的指纹也不适用，因为实时行情重放不回来（[决定记录](https://github.com/qOeOp/trade/blob/main/docs/plans/paper-run-storage-decision.zh.md)）。
