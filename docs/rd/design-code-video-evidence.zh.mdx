## 核验职责

| 阶段 | 代码职责 |
|---|---|
| Bundle / Probe | 目录与文件类型、严格 JSON、字段投影、公开 HTTPS 来源与敏感信息检查 |
| Media | 原始字节 SHA-256、容器与流、分辨率、大小和时长 |
| ASR | 固定引擎与模型、参数、语言、音频 PCM 哈希、分段结构与异常标记 |
| Frames / Crops | 覆盖网格、PTS、引用帧与裁剪的解码哈希和像素重算 |
| Claims | 连续语音段、数字、画面时间跨度、结构化旁证与显式性分类 |

## 结果语义

`ok` 汇总已有检查，`stages` 分别说明材料存在、失败或缺失，`flags` 给阅读者异常线索。成功不证明材料齐全或语义成立。`checker_git_blob` 标识实际执行的校验器。`--restored` 支持保留证据子集，已引用帧与裁剪仍须存在。
