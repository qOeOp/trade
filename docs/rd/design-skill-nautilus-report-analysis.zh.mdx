# skill 设计：nautilus-report-analysis

从封存原生报告的类型化表自算描述统计：比率、出场拆分、资金使用率、持仓结构、容量、折扣夏普、非劣集；只算 Agent 可自算的绩效指标。

**触发**　为研究决策计算绩效指标之外的任何统计前。

### 折扣夏普 [#def-nautilus-report-analysis-SKILL-md-deflated-sharpe]

`nautilus-report-analysis/SKILL.md`

- 计数只取 research status 中与该运行同一开发窗口的去重版本数与全部试验数；不自数，不剔除失败、中断或预检。
- 经 tables() 取交易窗口账户日收益，算日夏普 SR、偏度、原始峰度（正态为 3）与天数 T；全部用日频，不先年化。
- 试验间夏普方差 V 取同窗口全部经济证据可用研究运行的日夏普；不足两个时写明无法估计，不报 DSR。
- 期望最大夏普 SR0 = √V·((1−γ)Φ⁻¹(1−1/N) + γΦ⁻¹(1−1/(N·e)))，γ 为欧拉常数，N=1 时 SR0=0；DSR = Φ((SR−SR0)·√(T−1) / √(1 − 偏度·SR + (峰度−1)/4·SR²))。
- N 取去重版本数与全部试验数各算一次，报两端构成的范围，并列原始次数、V 与 T；不报单值，不当门槛或资格。
- 代码计数之外的搜索暴露读 research state 的 search_exposures，在范围旁写明，不改两端。
- 结果引用所依据的账本提交，可在该提交上重算；算过后记一条 search_exposure 判断，正文只引用运行与账本提交，不写 DSR 数值或计数。

### 读报告的提醒 [#def-nautilus-report-analysis-SKILL-md-selection-reminders]

`nautilus-report-analysis/SKILL.md`

### 资金使用率 [#def-nautilus-report-analysis-SKILL-md-capital-utilisation]

`nautilus-report-analysis/SKILL.md`

资金使用只从 tables(run_id, exposures=True, account=True) 算。标为 T 的敞口行，是下一根 K 线之前全部事件后仍持有的仓位，按 T 的标记价估值；某根没有行即空仓。报告四项：交易窗口全部 K 线上的时间加权平均名义额（空仓计零）及其占权益的比例、采样峰值（标明是采样峰值）、锁定保证金（含挂单）、在市时间。权益(T) 等于下一根之前最近一条账户总额加 T 的未实现盈亏。不重估仓位，不只凭账户报告推算。exposures 为空则不回答资金使用问题，并写进绩效指标局限；tables 拒绝则报告缺陷，不分析该运行。从首个有效根起每个有效运行都读；仓位或资金预算改动后必读。

### 非劣候选集 [#def-nautilus-report-analysis-SKILL-md-pareto-range]

`nautilus-report-analysis/SKILL.md`

- 总体只含经济证据可用的运行（economic_evidence_available 为真），按开发窗口与共同可交易范围分组；跨组不比较。
- 维度：账户年化、标记价回撤、夏普（引擎统计类）、计划胜率。A 支配 B＝四维都不差且至少一维更好；非劣集是不被支配者的集合。
- 报出成员（strategy_id@revision）、每维数值、账本提交与总体规模。
- 非劣集只描述推荐范围，不是资格，也不按单一指标排序；推荐可在集合外，但要写明取舍。
- 仅诊断、无效、未完成的候选分列，不进入计算。
- 驱动推荐的集合由第二个 Agent 独立复算，并提醒读者它是从许多候选里挑出来的。

### `drawdown-read-with-exposure` [#def-eval-nautilus-report-analysis-drawdown-read-with-exposure]

**验什么**　Agent 读回撤时连同同一运行的敞口一起读，不把敞口下降说成风险效率提高（R.3.1.2）。

**通过判据**　给定两个有效运行，后者的标记价回撤与平均名义额同时下降。通过须同时满足：输出把两者的资金使用率与回撤并列；结论写成敞口下降，不写成风险效率提高或风控改善；回撤取绩效指标，没有重算；净收益除以名义额如果出现，标为描述并写明分母，没有用来排序。任一条不满足即不通过。
