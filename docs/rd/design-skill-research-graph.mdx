# Research graph: research-graph

Draws one research line as a graph of strategy versions, replays, predictions, source reviews and decisions, built from the research ledger alone or from session transcripts alone. Comparing the two tests whether the ledger alone reconstructs the research.

## `SKILL.md` [#def-file-research-graph-SKILL-md]

**Trigger**　The user wants to see or draw a research line's history and progress; an audit tests what the ledger preserves against what a session did.

**Duties**

1. A graph has one source and is built by a fresh read-only sub-agent given only that source, its reference and the format; it never sees the other source, another graph or the author's conclusions, and what is missing stays null and goes into gaps.
2. A graph must pass `graph.py check`; the extraction is fixed, the format is never loosened to fit a source.
3. A comparison covers one line and one period; each difference is classed as a ledger gap, not a record, derivable or an extraction miss; only a ledger gap goes to product-doctor as a finding.
4. A comparison is evidence, not authority: a new stored field still needs the review and user decision AGENTS.md requires.
5. A new renderer reads only the view model; a new fact in the graph is a new format version, changed together in the format, both references, the layout and the comparison.

## Tool: services/research-graph

| Stage | Input → output | Owns |
|---|---|---|
| Extract | ledger or transcripts → graph.json (research-graph/1) | what happened, from one source (done by the Agent per the references) |
| Contract | graph.json → problems | the shape of a graph (schema/graph.schema.json) |
| Layout | graph.json → view.json (research-graph-view/1) | what to draw and where, in trial numbers and rows, no pixels; split into widgets (lineage/1, scatter/1, notes/1, candidate-detail/1), each with its own type, version and slot |
| Render | view.json → files | pixels, colours, labels and interaction; the static renderer writes one HTML file with no script |
| Compare | two graph.json → differences | which facts differ, without classing them |

Stages hand over only through these files, so each can be replaced alone. A richer renderer (for example one React component per widget type, with a web server sending widget documents over HTTP; the server only serves views and never reads or writes the ledger) reads the same widgets; static stays as the dependency-free fallback.
