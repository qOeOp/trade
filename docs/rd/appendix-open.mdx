## 待用户定

- **A** 『每条规则须能在账本审计或案例重放中观察到，观察不到就删』是否作为 skill 规则　仍属用户偏好；A.4.3.2 只写 skill 靠 eval 与独立前向检查验证；演练中未按此判据删过规则
- **A** 用户研究目标的条目（是否仍含胜率）及其在循环中的地位　A.2.3.3 只写改研究目标需用户授权；目标是报告参照而非代码门槛；eval own-sizing-not-user-constraint 提示词随之修订
- **E** 是否允许同时推进两条用户选定的研究路线　演练中只走过单路线，研究路线记录按一次一条设计（E.4.2.1）；是否放宽由用户定
- **L** 候补名单从哪来、由谁定　可由 Agent 按 <Ref id="L.1.1.1" /> 的收录标准提候补、用户选，尚未定；<Ref id="L.1.2.1" /> 只写换下一个候补并说明原因。
- **L** 第二批多品种／双腿模板的名单与启动时点　产品允许做现货，但名单未给；<Ref id="L.1.1.2" /> 只写第二批范围：横截面动量、配对、资金费 carry。
- **L** 模板首次回放的范围（全池全开发窗口一次到位，还是先有界先导）　演练中全池回放工程成本高，多数试验被生命周期、原生身份或容量阻断；<Ref id="L.2.2.1" /> 只写回放一次，范围由用户选。
- **T** 借用别的候选的部件，记为来源证据还是第二个研发父版本　正文写成一个研发父版本加来源证据（T.2.2.2）；若要第二父版本，须先经独立字段评审并把决定记入 docs/plans/。
- **H** 非收益维度（回撤、胜率、夏普）的配对推断口径　登记只接受年化收益维度，其他维度返回 METRIC_UNSUPPORTED；要支持它们，需先显式设计推断方法，再另行审议
- **H** 借用别的候选的部件，记为来源还是第二父　归 T 章候选谱系；正文按 T.2.2.2 写成一个研发父版本加来源证据，是否允许第二父由用户定
- **V** 非收益维度（回撤、胜率、夏普）的配对推断　夏普差可用学生化循环块自助（与 V.3.2.1 同机制）作第二个可登记维度；回撤是路径统计量、胜率两侧计划数不等，无成熟配对设计；扩维度改拒绝边界须用户授权。
- **F** 诊断判据看绝对读数还是配对差　建议默认：部件判据读候选自身绝对读数（R 口径，注明总体）；相对比较对照的改善只读配对读数（V 口径）；两者并列不混用
- **F** 三篇 Agent 自评预印本是否够格作依据　F.3.1.1 的依据按演练证据写，不引这些预印本；用户认可后再补
- **X** 回溯窗口（开发暴露外的历史时段、同期其他标的）能否登记为降级的样本外　只认凭证之后开始的窗口，已存在数据只作探索或反驳（<Ref id="X.1.2.3" />）；若允许降级登记，需另立准入规则与分级用语。
- **X** 独立复读是否在本章留一句　读数由代码算，通则见 <Ref id="R.1.2.3" />；若用户要求，在 <Ref id="X.2.1.4" /> 加一句：样本外结论段由干净上下文的第二个 Agent 复读报告。
- **X** 数据被修正或运行环境变更后，进行中的样本外登记怎么办　窗口数据已存在就不能再登记；修正数据只按 retry_of 重试使用；运行环境或账户条款不一致即拒绝绑定。是否作废登记、如何记录归 D 章。
- **C** 部分成交对齐、成交时刻、按缺口补挂升格为具名审计项　升格须用户授权改动审计检查；授权前由 <Ref id="C.6.2.1">独立源码审查</Ref> 与 <Ref id="G.3.3.1">裸仓审计</Ref> 覆盖，不进代码。
- **C** 用引擎的成交／延迟模型做撮合保守化　属回放环境的撮合假设，见 <Ref id="W.5.1.2" />；策略文件契约不涉。
- **W** 外部数据按发布时刻对齐（point-in-time）是否在本章另立一节　做法见 research-sources 的数据参考（point-in-time、ALFRED vintage）；本章暂不含，外部数据来源归 H 章
- **W** 撮合保守化配置与加压读数（引擎撮合模型的滑点与排队）是否扩成功能　引擎撮合模型可配滑点与排队（官方文档）；需新运行环境并重跑全部候选，只报告不裁决；本章只列为局限（W.5.1.2）
- **W** 杠杆与保证金率归环境条款还是策略设计变量　本章写为运行器固定的环境条款（W.4.1.2、W.4.2.2）；改为设计变量需新运行环境并重跑全部候选
- **W** 预热期下单由代码拒绝还是源码自律　本章写为源码自律加原生预检与独立源码审查；改为代码拒绝属改变拒绝边界，需用户授权
- **W** 下架结算价的权威来源　交易所公告给禁新仓与结算时刻，不给结算价算法；无权威价时只供给终止时钟并要求终止前空仓（W.3.2.2）
- **G** 审计是否核验成员禁新仓后无新开仓　成员禁新仓后不开新仓属策略文件契约；加为审计项是收紧审计检查，需用户授权。引擎 PRE_CLOSE 状态是否自动拒绝非只减仓单尚未经原生试验确认。
- **R** 行情归因（对主流合约或等权篮子的 beta/alpha，买入持有与等权零参照）　引擎统计类支持带基准的收益计算；「优势是否只是资金费收割」由 R.2.3.3 承接
- **R** 回撤的块自助分布　配对块自助检验只给均值与年化差的区间；回撤分布是否作报告读数未定
- **R** 回测过拟合概率（PBO/CSCV）只作报告读数　论文方法与开源参照实现已核实；是否进入报告未定
- **J** 账本内 Dolt branch 与 tag 的组织，及写账号的 branch 授权范围　单一固定研究 branch，还是按市场或开发窗口分 branch；J.3.3.1 按单一固定研究 branch 写
- **J** 公共时间戳凭证（RFC 3161）是否保留　删去则 J.4 只剩服务器时间，样本外窗口准入失去外部先后证明；J.4.2.2 按保留写
- **J** AGENTS.md 与 research/records/README.md 入账清单中样本外条目的英文用词　拟统一为 out-of-sample validations；J.1.1.1 引用该清单，用词随用户定
- **J** 研究路线记录的载体：固定命名证据包 research-line.json 还是独立表　J.2.1.2 按证据包写；改为表须先按 AGENTS.md 做独立字段评审并记入 docs/plans/
- **D** 上游交易所公布历史数据修正时怎么办　市场库只追加，改写已存月份或来源冲突即拒绝（POOL_CHANGED／SOURCE_CONFLICT），历史修正进不来；是否另立市场库身份承接修正待用户定。
