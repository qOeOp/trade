# X　样本外验证：用户发起的一次性检验：样本外验证由谁发起，怎样登记与准入，怎样一次性回放并照实报告。

本章讲用户认可一个候选之后，怎样在登记之后才开始的新窗口上只回放一次，并照实报告。它沿用 H 章的登记和 R 章的绩效指标，但不属于研究循环。登记、窗口先后、一次性和一致性由代码与账本锁住，用语由 skill 指导。

## X.1　发起、登记与准入 [#X-1]

<Steps>

<Step>

用户认可一个候选，指定被验版本、窗口和共同可交易范围。

</Step>

<Step>

登记写进账本，并取一份公共时间戳凭证：外部机构签发，证明登记在那一刻已存在。

</Step>

<Step>

窗口结束、新数据进入新的市场提交后，用户发起一次样本外回放。

</Step>

<Step>

回放启动前，代码逐项核对它与登记一致，并把登记绑定到这次试验。

</Step>

<Step>

任一项不符就整笔撤回，回放不启动。

</Step>

</Steps>

### X.1.2　登记与窗口准入 [#X-1-2]

登记锁住被验对象，窗口必须在登记之后才开始。

<Cap id="X.1.2.1" kind="database" tier="verified" tierLabel="已验证" title="样本外回放前先登记入账，并取公共时间戳凭证">

- 登记锁定四样：被验候选、共同可交易范围、窗口和检验条件。
- 登记入账后，把它所在账本版本的哈希交给公共时间戳机构，换回凭证。
- 凭证证明这份计划在某一时刻已经存在，但不证明它是唯一的计划。
- 登记只追加不改；取凭证失败时登记仍在，须在窗口开始前补取。

- 登记时，窗口起点不晚于登记时间就拒绝。
- 回放前再核一次：没有凭证，或凭证时间不早于窗口起点，就拒绝。
- 窗口在登记之后才开始，所以登记时窗口内的数据还不存在。
- 这一条同时排除了窗口与开发数据重叠、旧运行冒充和窗口重复使用。

### X.1.3　一次性与一致性 [#X-1-3]

一次登记只换一次回放，回放必须与登记逐项相同。

<Cap id="X.1.3.1" kind="database" tier="unverified" tierLabel="待验证" tierNote="缺一登记一回放与重试条件在账本上的实际拒绝记录。" title="一次登记只能绑定一次回放，绑定即消耗">

- 登记和这次回放的试验在同一笔写入里绑定，第二次绑定被拒绝。
- 回放中断、运行无效或没有实质活动时，登记同样已经消耗。
- 只有中断且无运行、运行无效、无经济证据资格三种情况，才可另行登记重试。
- 重试的候选、窗口和范围须与原登记相同；结果不好看不是重试理由。

- 运行环境须是正式自动构建、按摘要钉死的；源码须是登记的那一版。
- 范围规则与登记前各月的成员名单不变，窗口内的成员不得被剔除。
- 交易落在登记窗口内，回放在窗口结束后发起，各合约输入覆盖齐全。
- 账户配置与这个候选最近一次有效的研究回放相同。

## X.2　报告结果 [#X-2]

<Steps>

<Step>

运行封存并绑定登记后，Agent 读取样本外报告。

</Step>

<Step>

代码给出与开发报告同口径的绩效指标，没有经济证据资格时置空。

</Step>

<Step>

代码给出窗口内日收益的区间和 p，并按同窗口登记的个数校正 p。

</Step>

<Step>

Agent 补算用了多少资金，照实转述，并写明模拟成交和短窗口的局限。

</Step>

<Step>

Agent 立即把报告交给用户，由用户判断认不认可。

</Step>

</Steps>

### X.2.1　绩效指标 [#X-2-1]

代码只读账本，算绩效指标、区间和校正，不下裁决。

<Cap id="X.2.1.1" kind="code" tier="unverified" tierLabel="待验证" tierNote="缺样本外报告的实际产出，以及它与开发报告口径的逐项对照。" title="样本外报告与开发报告同口径，无资格即置空，不下裁决">

- 绩效指标从绑定的封存运行读出，口径与开发报告相同。
- 没有经济证据资格时，绩效指标置空，只留原因和诊断。
- 报告列出登记内容、凭证时间、审计状态和这个候选的全部样本外登记。
- 报告不写账本，也没有通过、裁决或推荐。

- 序列是窗口内交易段的账户日收益，按日历日计，无缺无重；不可用就置空。

- p 是策略若无效、仍碰巧这么好的概率，不是策略有效的概率。

- 报告并列原始 p 和校正后的 p，区间也按个数放宽，不判通过。

## 待定事项 [#X-pending]

**待用户定**

- **回溯窗口（开发暴露外的历史时段、同期其他标的）能否登记为降级的样本外**　只认凭证之后开始的窗口，已存在数据只作探索或反驳（<Ref id="X.2.2.2" />）；若允许降级登记，需另立准入规则与分级用语。
- **独立复读是否在本章留一句**　绩效指标由代码算，通则见 <Ref id="R.1.2.3" />；若用户要求，在 <Ref id="X.2.1.4" /> 加一句：样本外结论段由干净上下文的第二个 Agent 复读报告。
- **数据被修正或运行环境变更后，进行中的样本外登记怎么办**　窗口数据已存在就不能再登记；修正数据只按 retry_of 重试使用；运行环境或账户条款不一致即拒绝绑定。是否作废登记、如何记录归 D 章。

- **不进文档**　样本外回放是否计入研究尝试计数：样本外试验照写 trial 行，研究计数把样本外单列（<Ref id="V.4.4.1" />）；计数不触发任何规则，本章不另写。
