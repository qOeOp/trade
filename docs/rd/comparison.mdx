### V.2.2　配对的双方与单位 [#V-2-2]

配对双方是两份通过审计的封存运行，单位是逐日对齐的账户日收益。

<Cap id="V.2.2.1" kind="code" tier="rehearsal" tierLabel="演练证据" title="候选用本登记网格点的运行，对照用登记声明的那份">

- 两边都要通过完整性审计并已封存，用途是研究或样本外验证。
- 候选运行须出自本登记某个网格点的试验，源码与该点一致。
- 对照是登记声明的比较对照，不必是研发父版本的运行。
- 登记没有声明对照时，比较直接拒绝。

</Cap>

<Cap id="V.2.2.2" kind="code" tier="verified" tierLabel="已验证" title="配对单位是交易窗口内逐日对齐的账户日收益">

1. 每边读引擎原生日收益，丢掉交易窗口前的预热段。
2. 核时间戳按 UTC 切日、逐日连续、覆盖整个交易窗口。

4. 核两边日历逐日一致，不一致就拒绝比较。
5. 任一步不满足，该边序列不可用并写明局限，不插补也不重采样。

## V.3　做配对检验：效应、区间和 p 怎么算 [#V-3]

<Steps>

<Step>

取两边逐日对齐的账户日收益和登记锁定的检验条件。

</Step>

<Step>

再核一遍检验条件和序列形态，不合格就拒绝，什么数都不出。

</Step>

<Step>

逐日取对数收益差，两边共用同一组块起点重抽，得出效应、区间和 p。

</Step>

<Step>

按本次网格点数校正 p 和区间覆盖。

</Step>

<Step>

加报块长敏感性、差值集中度和能分辨的最小效应，连同局限一起返回。

</Step>

</Steps>

### V.3.2　检验方法 [#V-3-2]

检验结果含效应、三种区间、单侧 p 和校正后 p，全部由一次只读计算给出。

<Cap id="V.3.2.1" kind="code" tier="verified" tierLabel="已验证" title="两边共用块起点做配对块重抽，得出单侧 p">

1. 逐日取两边对数收益之差，观测效应是它的均值。
2. 按登记块长切成首尾循环衔接的块。
3. 用登记种子重抽，两边共用同一组块起点，保留配对和时间相依。
4. 重抽得到的均值差减去观测效应，得到中心化分布。
5. p 是中心化值不小于观测效应的比例，分子分母各加一。

<div className="rd-foot"><span className="rd-guard">代码</span> <span className="rd-impl">实现 <Ref id="report.paired">paired</Ref> <Ref id="registration.validate_design">validate_design</Ref></span></div>

</Cap>

<Cap id="V.3.2.2" kind="code" tier="verified" tierLabel="已验证" title="日对数差给基本区间和学生化区间，年化差另给百分位区间">

- 基本区间由中心化分布的分位数反射得到。
- 学生化区间在每次重抽里再重抽一层，估出效应的波动幅度（标准误）再定区间。
- 年化差的百分位区间单独呈现，不与 p 混称，也不检验最小改进。
- 波动幅度估不出时，相应区间和 p 留空并写局限，不拿别的区间顶替。

<div className="rd-foot"><span className="rd-guard">代码</span> <span className="rd-impl">实现 <Ref id="report.paired">paired</Ref></span></div>

</Cap>

<Cap id="V.3.2.3" kind="code" tier="verified" tierLabel="已验证" title="按本次登记的网格点数校正 p 和区间覆盖">

- 每个网格点各自与登记的对照比较，不挑代表点。
- 区间覆盖取 1 减去「显著性水平除以网格点数」。
- 校正后 p 是原始 p 乘网格点数，最大为 1。
- 校正只管本次登记，不代表跨登记误差受控，这句随结果返回。

### V.3.3　稳健性数字 [#V-3-3]

每次检验结果都带上这些数字，供 Agent 核对样本量、时间相依和能分辨的效应。

<Cap id="V.3.3.1" kind="code" tier="verified" tierLabel="已验证" title="一律加报三档块长敏感性和差值集中度">

- 在半倍、一倍、两倍登记块长下各报一次基本区间和单侧 p。
- 交易天数不到该档块长两倍时，该档标为不可用，不给数。
- 差值集中度是绝对差最大的五天占全部绝对差的比例。
- 这些只作参考，不拿来挑块长或挑版本。

<div className="rd-foot"><span className="rd-guard">代码</span> <span className="rd-impl">实现 <Ref id="report.paired">paired</Ref></span></div>

</Cap>

<Cap id="V.3.3.2" kind="code" tier="verified" tierLabel="已验证" title="加报本次样本按 80% 把握能分辨的最小效应">

- 按重抽得到的波动幅度估算本次样本能分辨的最小日对数差。
- 80% 把握是未校准的示例值，随方法版本固定。
- 预计效应比它小时，不显著不算否定证据。
- 它与登记的最小改进并列呈现，两者都不当门槛。

### V.4.1　检验结果的内容与身份 [#V-4-1]

检验结果只有效应、区间、p、检验条件和局限，附一组身份，没有裁决。

<Cap id="V.4.1.1" kind="code" tier="rehearsal" tierLabel="演练证据" title="检验结果只给效应、区间、p 和条件，不含裁决">

- 内容只有效应、区间、p、检验条件和局限五组。
- 结果里没有通过、资格或推荐这类结论。
- 比较不改变候选的身份、谱系，也不改变它当父版本的资格。
- 亏损或不显著的有效候选照常可以派生。

## 待定事项 [#V-pending]

**待用户定**

- **非收益维度（回撤、胜率、夏普）的配对推断**　夏普差可用学生化循环块自助（与 V.3.2.1 同机制）作第二个可登记维度；回撤是路径统计量、胜率两侧计划数不等，无成熟配对设计；扩维度改拒绝边界须用户授权。

- **不进文档**　全程自适应搜索的误差控制（试验次数折扣、DSR、PBO、ONC）：归 R 章试验计数与折扣夏普绩效指标；本章只在 V.3.2.3 写明 Bonferroni 只校正本次网格、不控制全程搜索。
- **不进文档**　显著性水平、最小改进的数值：由 Agent 登记时声明并写设计理由（H.3.2.2），正文一律写「未校准示例值」，不作常数。
- **不进文档**　策略嵌入离线拟合常量绕过网格计数：归 C 章源码契约与独立源码审查；比较只认已发布源码的内容哈希。
- **不进文档**　双父合成版本与谁比：合成版本按 T 章一父加来源证据处理；本章由「对照由登记声明、不必是父版本」（V.2.2.1）覆盖。
- **不进文档**　自动选点（贝叶斯优化、Thompson sampling、部分因子）：产品不做自动选点；H 章只留交互实验一句并标待验证。
- **不进文档**　「配对检验与候选流程提高研发成功率」的主张：两次演练无同条件新旧流程对照，属待验证，不写成本章任何能力；本章只写方法与边界。
