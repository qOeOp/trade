# Database｜数据库

研究账本是一个 Dolt 数据库，当前模式为第 1 代（`ledger/schema.sql`，代码里的 `SCHEMA_VERSION`）。用户 2026-11-10 备份并删除了旧账本，第 1 代从空账本开始，不迁移旧数据。1.0 之前，模式一变就开新账本，不迁移数据（AGENTS.md）；同一代内口径变了，读数层（`run_reading`）由重封按新代码重算。

表分三层：

- **承诺**：除 `run_reading` 外的业务表。只追加，写账号只有 SELECT 和 INSERT；`ledger review` 报告任何被改或被删的行。
- **读数**：`run_reading`。每个通过运行一份当前读数，只有产品的封存命令能写，重封时凭指纹替换，旧值留在 Dolt 历史和公开副本。
- **写入协调**：`ledger_head` 单行，写账号可以 UPDATE。

每次写入恰好一个事务、一个 Dolt 提交、一行 `ledger_head`；证明先后的时间由服务器触发器写，内容哈希是生成列。Paper 运行存在独立的 Paper 库，市场数据是市场目录里的 Parquet 文件，都不在研究账本里。

按记录职责查表：先看事实属于哪一类，再看字段、关联和写入方。
