# Database｜数据库

当前研究账本为模式第 3 代：一次执行只用 `trial_id`，结果表与子表复用它；旧第 2 代账本保持原样，由固定旧版代码读取，不原地迁移或重写历史。新库不清除既有研究暴露，接续须先明确跨代边界。

按记录职责查表：先看事实属于哪一类，再看字段、关联和写入方。

| 职责 | 保存或提供什么 |
|---|---|
| [候选与谱系](/zh/docs/design-database-candidates/) | 保存完整策略源码、内容身份与父版本关系；候选版本是谱系中的节点。 |
| [试验与登记绑定](/zh/docs/design-database-trials/) | 记录每次执行的身份、用途与窗口，以及登记网格点消耗了哪次试验。 |
| [运行结果与封存读数](/zh/docs/design-database-runs/) | 分别保存执行有效性、审计与指纹、封存报告、逐日收益和原生持仓周期。 |
| [证据包与原件](/zh/docs/design-database-evidence/) | 证据包组织文件目录，目录指向按内容哈希存储的原件；研究线与登记声明也使用证据包，不另造重复记录。 |
| [研究判断与主体](/zh/docs/design-database-judgments/) | 保存只追加的研究判断、取代关系，以及判断针对的候选、试验和登记主体。 |
| [样本外登记与时间见证](/zh/docs/design-database-validation/) | 保存事前检验声明、一次执行绑定与时间凭证；凭证证明提交在给定时间前已存在。 |
| [市场数据与交易范围](/zh/docs/design-database-market/) | 保存合约规格、成交价与标记价 K 线、资金费率和逐月共同交易范围。 |
| [模式版本与写入协调](/zh/docs/design-database-coordination/) | 记录库模式版本与账本写入协调身份；Dolt 系统表和版本内测试负责历史读取与约束核对。 |
| [读取视图与研究史](/zh/docs/design-database-views/) | 汇集候选、试验、运行、判断、证据和样本外登记的读取视图，以及跨研究线的历史查询。视图是派生读口，不是额外存储或访问边界。 |
