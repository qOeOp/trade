## 读取视图

各流程经这些视图读账本；底表只由写入它的功能、视图定义与读字节或原生报表的入口直接读。历史读取按「库/提交」的修订库读，得到当时的视图定义。视图不是访问边界。

| 表 | 用途 |
|---|---|
| <Ref id="table:v_candidates">v_candidates</Ref> | 候选的身份与谱系，不含源码字节 |
| <Ref id="table:v_trials">v_trials</Ref> | 每次试验及其登记网格点、样本外绑定与运行状态；路线内试验、研究计数与前置门都读它 |
| <Ref id="table:v_runs">v_runs</Ref> | 运行的身份、审计结论与存储的绩效指标；指标在读取入口里按资格遮蔽后才流出 |

CREATE VIEW v_trials AS

       b.registration_id AS validation_registration, t.image_digest,

### `universe_month` [#def-table-universe_month]

共同可交易范围 universe：环境按事前规则在每个 UTC 月初产出的成员名单，不排名、不取前 N；后来下架的合约留在当时名单里；成员时间路径由本表按 AS OF 派生

<TypeTable type={{ "universe_rule": { type: "VARCHAR(60)", description: "产出该行的范围规则版本；不同版本的名单共存，旧行不改", required: true }, "month": { type: "DATE", description: "UTC 月初", required: true }, "symbol": { type: "VARCHAR(40)", description: "成员合约的交易所公开名；ticker 重用在导出时按生命周期拆为原生合约", required: true } }} />

**键与约束**

- 主键　`universe_rule`, `month`, `symbol`
- CHECK　`DAYOFMONTH(month) = 1`

**Dolt 能力**

- **W.1.3.2**　随导入在同一提交追加；导入前重算全部月份并与已存行比对，不一致 UNIVERSE_CHANGED 拒绝，旧提交上的名单不被改写
- **D.1.1.1**　dolt_diff_universe_month 只应出现 added；AS OF 重现任一提交的成员时间路径
- **W.3.1.2**　AS OF market_commit 派生范围规则、合约清单与每合约 [start, end) 成员时间路径，进入输入身份
- **X.1.3.1**　样本外绑定时在登记的 market_commit 与本次 market_commit 下逐行比对登记前各月名单
