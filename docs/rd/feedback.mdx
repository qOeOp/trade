## F.1　读取反馈：先定资格，再拆到职责 [#F-1]

<Steps>

<Step>

先读运行的经济证据资格；没有资格的，绩效指标已被置空。

</Step>

<Step>

没有资格的运行按成因分诊断或修复两路处理。

</Step>

<Step>

有资格的运行读绩效指标和原生报告，看钱从哪来、怎样出场。

</Step>

<Step>

登记带了比较对照的，再读检验结果。

</Step>

<Step>

按五步诊断，把事实、解释和拟改的策略职责分开写成判断记录。

</Step>

</Steps>

### F.1.1　反馈资格 [#F-1-1]

先看运行有没有经济证据资格，没有的按成因分诊断与修复两路。

<ul className="rd-rules">
<li id="F-1-1-1"><span className="rd-rule-id">F.1.1.1</span> 先读经济证据资格；零成交运行只作诊断，不与亏损运行比优劣 <Ref id="rule:F.1.1.1">research-round · references/diagnosis.md</Ref></li>
<li id="F-1-1-2"><span className="rd-rule-id">F.1.1.2</span> 运行无效、未完成或预检未过只修复，不当反馈，修好另行登记 <Ref id="rule:F.1.1.2">research-round · references/diagnosis.md</Ref></li>
</ul>

### F.1.2　绩效指标的读法 [#F-1-2]

绩效指标的口径前面已讲，这里只讲怎样读出场原因。

<ul className="rd-rules">
<li id="F-1-2-2"><span className="rd-rule-id">F.1.2.2</span> 出场原因只读平仓单的标签或类型，不按盈亏推断，未平仓单列 <Ref id="rule:F.1.2.2">nautilus-report-analysis · references/exit-reasons.md</Ref></li>
</ul>

### F.1.3　诊断顺序 [#F-1-3]

诊断由 skill 指导，按固定顺序走完再提假设，结论写成判断记录。

<ul className="rd-rules">
<li id="F-1-3-1"><span className="rd-rule-id">F.1.3.1</span> 先按资格、钱从哪来、过程、稳定性、机制五步诊断，再提假设 <Ref id="rule:F.1.3.1">research-round · references/diagnosis.md</Ref></li>
</ul>

## F.2　更新研究优先级：决定下一步改什么 [#F-2]

<Steps>

<Step>

读诊断、检验结果，以及研究状态里的当前判断和未复盘试验。

</Step>

<Step>

按效应、不确定性等依据给下一研究动作排序。

</Step>

<Step>

结合来源选出候选假设，定研发父版本和比较对照。

</Step>

<Step>

把排序和理由写成一条研究优先级判断入账。

</Step>

<Step>

回到提假设，登记之后才回放。

</Step>

</Steps>

### F.2.1　优先级的依据与边界 [#F-2-1]

排下一研究动作的依据，以及哪些结果不构成排除某个方向。

<ul className="rd-rules">
<li id="F-2-1-1"><span className="rd-rule-id">F.2.1.1</span> 按效应、不确定性、机制、覆盖、信息价值和成本排序，不排除方向 <Ref id="rule:F.2.1.1">research-round · references/feedback.md</Ref></li>
</ul>

## F.3　复盘与推荐：节奏触发，研究默认继续 [#F-3]

<Steps>

<Step>

每次更新优先级后读研究状态，看未复盘试验是否到了节奏。

</Step>

<Step>

没到就继续登记下一实验；到了就复盘。

</Step>

<Step>

复盘时在全部有资格候选上给综合推荐，并说明取舍。

</Step>

<Step>

推荐、下一实验的父版本与对照、新的复盘节奏各写一条判断。

</Step>

<Step>

要换研究路线或选新根时，给出选项并提问，由用户选。

</Step>

</Steps>

### F.3.1　复盘的触发与计数 [#F-3-1]

复盘何时触发由 Agent 自定节奏，次数从账本读。

<ul className="rd-rules">
<li id="F-3-1-1"><span className="rd-rule-id">F.3.1.1</span> 复盘用的次数只读账本计数，可比候选数取有经济证据资格的 <Ref id="rule:F.3.1.1">research-round · references/review.md</Ref></li>
<li id="F-3-1-2"><span className="rd-rule-id">F.3.1.2</span> 复盘节奏只触发复盘，不因次数多少停止研究或判方向无效 <Ref id="rule:F.3.1.2">research-round · SKILL.md</Ref></li>
</ul>

### F.3.2　复盘的内容 [#F-3-2]

在全部有经济证据资格的候选上综合推荐，与下一实验的父版本分开定。

<ul className="rd-rules">
<li id="F-3-2-1"><span className="rd-rule-id">F.3.2.1</span> 推荐前在全部有经济证据资格的候选（含旧的）上多维比较 <Ref id="rule:F.3.2.1">research-round · references/review.md</Ref></li>
</ul>
