# 样本外登记与时间见证

样本外登记是用户发起的一次性检验声明：窗口在登记之后，执行只绑定一次；登记提交随后取 RFC 3161 时间戳凭证，证明它早于窗口起点就已存在。

[数据库总览](/zh/docs/design-ledger/)

### `validation_registration` [#def-table-validation_registration]

样本外登记：一个候选、范围规则、窗口和比较方法；窗口起点晚于登记时刻（重试除外，重试保持原登记的候选、范围规则和窗口）

<TypeTable type={{ "registration_id": { type: "INT AUTO_INCREMENT", description: "登记编号，自增", required: true }, "source_sha256": { type: "CHAR(64)", description: "被验证的候选", required: true }, "market_day": { type: "DATE", description: "登记时的市场日", required: true }, "universe_rule": { type: "VARCHAR(60)", description: "共同交易范围规则", required: true }, "window_start": { type: "DATETIME(6)", description: "验证窗口起点 UTC", required: true }, "window_end": { type: "DATETIME(6)", description: "验证窗口终点 UTC，不含", required: true }, "comparison_design_id": { type: "INT", description: "承诺的比较方法", required: true }, "retry_of": { type: "INT", description: "重试的原登记；复合外键要求候选、范围规则和窗口相同", required: false }, "op_id": { type: "VARCHAR(160)", description: "幂等操作 ID：同一载荷重试返回原记录；UNIQUE", required: true }, "created_at": { type: "DATETIME(6)", description: "服务器 UTC 时间，BEFORE INSERT 触发器覆盖调用方给的值；非重试登记的 window_start 必须晚于它（CHECK）", required: true } }} />

**键与约束**

- 主键　`registration_id`
- 唯一　`op_id`
- 唯一　`registration_id`, `source_sha256`, `universe_rule`, `window_start`, `window_end`
- 外键　`source_sha256` → <Ref id="table:candidate">candidate</Ref> `source_sha256`
- 外键　`comparison_design_id` → <Ref id="table:comparison_design">comparison_design</Ref> `design_id`
- 外键　`retry_of`, `source_sha256`, `universe_rule`, `window_start`, `window_end` → <Ref id="table:validation_registration">validation_registration</Ref> `registration_id`, `source_sha256`, `universe_rule`, `window_start`, `window_end`
- CHECK　`window_start \< window_end`
- CHECK　`retry_of IS NULL OR retry_of \< registration_id`
- CHECK　`retry_of IS NOT NULL OR window_start > created_at`

**保护与读写规则**

- 一次写入一个事务、一个 Dolt 提交，并把 `ledger_head` 加一；写账号对本表只有 INSERT，`ledger review` 报告任何被改或被删的行（ROW_CHANGED）
- 样本外试验以复合外键对上本行的候选、范围规则和窗口；`trial` 上的唯一键保证一次登记只绑定一次试验

**写入方**　`registration.validation.validation_register`（`validation registration`）

**读取方**　`validation report`

### `witness` [#def-table-witness]

时间见证：插入样本外登记的那个提交的 RFC 3161 时间戳凭证；时间取凭证的 genTime，按钉住的根证书离线核验

<TypeTable type={{ "commit_hash": { type: "CHAR(32)", description: "被见证的提交（32 位 Dolt 哈希）", required: true }, "registration_id": { type: "INT", description: "该提交插入的样本外登记；一次登记只有一份凭证", required: true }, "token": { type: "LONGBLOB", description: "RFC 3161 时间戳凭证原字节", required: true } }} />

**键与约束**

- 主键　`commit_hash`
- 唯一　`registration_id`
- 外键　`registration_id` → <Ref id="table:validation_registration">validation_registration</Ref> `registration_id`
- CHECK　`LENGTH(commit_hash) = 32`
- CHECK　`LENGTH(token) > 0`

**保护与读写规则**

- 一次写入一个事务、一个 Dolt 提交，并把 `ledger_head` 加一；写账号对本表只有 INSERT，`ledger review` 报告任何被改或被删的行（ROW_CHANGED）
- `ledger review` 报告见证的提交不是插入其登记的提交，或不在本分支历史里（WITNESS_UNBOUND）

**写入方**　`ledger.witness.witness`（`ledger witness`）

**读取方**　`ledger.witness.registration_stamp`（验证准入与报告）
