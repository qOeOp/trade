# 证据包与原件

证据包是一组命名文件，文件按内容哈希指向只存一份的原件。包的种类说明它装什么；产品种类只由产品代码写，Agent 只写自己的包。

[数据库总览](/zh/docs/design-ledger/)

### `evidence_bundle` [#def-table-evidence_bundle]

证据包：名字即身份，从不替换。试验的 start、capture、recovery 包以 `trial-<id>-` 开头并在本行记下试验

<TypeTable type={{ "bundle": { type: "VARCHAR(160)", description: "包名，`[A-Za-z0-9][A-Za-z0-9_.-]{0,159}`；`trial-<id>-…` 与 `lifecycle-…` 是产品保留的名字", required: true }, "kind": { type: "ENUM('start', 'capture', 'recovery', 'lifecycle', 'source', 'agent')", description: "start 试验开始（源码与覆盖回执）；capture 捕获；recovery 恢复；lifecycle 某市场日的上下架事实；source 登记引用的来源原件（`source-<sha256>`）；agent Agent 自己的证据", required: true }, "trial_id": { type: "INT", description: "start、capture、recovery 包所属试验；其他种类为 NULL", required: false }, "one_per_trial": { type: "VARCHAR(16) 生成列", description: "start 或 capture 时等于种类，用唯一键保证一次试验最多一个开始包和一个捕获包（由 `IF(kind IN ('start', 'capture'), kind, NULL)` 生成）", required: false }, "op_id": { type: "VARCHAR(160)", description: "幂等操作 ID；随业务行写入的包可为 NULL", required: false }, "created_at": { type: "DATETIME(6)", description: "服务器 UTC 时间，BEFORE INSERT 触发器覆盖调用方给的值", required: true } }} />

**键与约束**

- 主键　`bundle`
- 唯一　`op_id`
- 唯一　`trial_id`, `one_per_trial`
- 外键　`trial_id` → <Ref id="table:trial">trial</Ref> `trial_id`
- CHECK　`(kind IN ('start', 'capture', 'recovery')) = (trial_id IS NOT NULL)`
- CHECK　`trial_id IS NULL OR bundle LIKE CONCAT('trial-', trial_id, '-%')`

**保护与读写规则**

- 一次写入一个事务、一个 Dolt 提交，并把 `ledger_head` 加一；写账号对本表只有 INSERT，`ledger review` 报告任何被改或被删的行（ROW_CHANGED）
- 包与它的业务行同一提交写入

**写入方**　`ledger.evidence.write_files`（产品种类）；`ledger.evidence.add_bundle`（`evidence add`，种类 agent）

**读取方**　`evidence export`、`ledger.evidence.load_bundle`

### `evidence` [#def-table-evidence]

包内文件目录：包名 × 路径 → 内容哈希

<TypeTable type={{ "bundle": { type: "VARCHAR(160)", description: "所属包", required: true }, "path": { type: "VARCHAR(512)", description: "包内相对路径，最长 512", required: true }, "sha256": { type: "CHAR(64)", description: "内容哈希；只能指向已存在的原件", required: true } }} />

**键与约束**

- 主键　`bundle`, `path`
- 索引　`sha256`
- 外键　`bundle` → <Ref id="table:evidence_bundle">evidence_bundle</Ref> `bundle`
- 外键　`sha256` → <Ref id="table:evidence_content">evidence_content</Ref> `sha256`

**保护与读写规则**

- 一次写入一个事务、一个 Dolt 提交，并把 `ledger_head` 加一；写账号对本表只有 INSERT，`ledger review` 报告任何被改或被删的行（ROW_CHANGED）

**写入方**　`ledger.evidence.write_files`

**读取方**　`ledger.evidence.load_bundle`（读回时重算哈希）

### `evidence_content` [#def-table-evidence_content]

原件：按内容只存一份；哈希由库内生成，写入方不能把改过的字节配上旧哈希

<TypeTable type={{ "sha256": { type: "CHAR(64) 生成列", description: "内容哈希（主键）（由 `SHA2(content, 256)` 生成）", required: true }, "content": { type: "LONGBLOB", description: "原字节，非空", required: true } }} />

**键与约束**

- 主键　`sha256`
- CHECK　`LENGTH(content) > 0`

**保护与读写规则**

- 已有的内容只被引用，不再插入；写账号只有 INSERT

**写入方**　`ledger.evidence.write_files`
