# L　策略库：候选谱系的根从哪来，怎样入账并得到第一份可比较的报告。

<p className="rd-translation-note">English translation pending: this page shows the Chinese source text.</p>


本章回答谱系的根从哪来、怎样得到第一份报告。根有两种：有公认一手出处的策略库模板，和用户提供信息源的人造根。转写守策略文件规则，出处只说明来源、不为参数背书；回放走同样的登记，只是不带父版本和对照。

## L.1　从出处或用户信息源转写成根文件 [#L-1]

<Steps>

<Step>

收录：只取有公认一手出处的原版策略，或用户提供信息源的人造根。

</Step>

<Step>

留存：出处原件与检索记录作为证据包入账。

</Step>

<Step>

核实：每个默认参数都在出处原件里找到位置，找不到就换候补。

</Step>

<Step>

重写：照出处写成单个策略文件，文件头写明出处和 27 项职责立场。

</Step>

<Step>

发布：作为没有父版本的根入账，能否跑通由原生预检和独立源码审查判定。

</Step>

</Steps>

### L.1.1　收录 [#L-1-1]

判定一个原版策略能不能收进策略库。

<ul className="rd-rules">
<li id="L-1-1-2"><span className="rd-rule-id">L.1.1.2</span> 只转写首批名单内 12 个单品种策略，核实不了换候补不放宽 <Ref id="rule:L.1.1.2">research-round · references/template.md</Ref></li>
</ul>

### L.1.2　核实 [#L-1-2]

确认每个默认参数都出自出处原件。

<ul className="rd-rules">
<li id="L-1-2-1"><span className="rd-rule-id">L.1.2.1</span> 每个默认参数都要在出处原件里找到位置，找不到就弃用该模板 <Ref id="rule:L.1.2.1">research-round · references/template.md</Ref></li>
</ul>

### L.1.3　重写与文件头 [#L-1-3]

照出处写成策略文件，并在文件头写明出处与职责立场。

<ul className="rd-rules">
<li id="L-1-3-1"><span className="rd-rule-id">L.1.3.1</span> 照出处从头重写，不加无出处的规则或参数，必需的补选须列明 <Ref id="rule:L.1.3.1">research-round · references/template.md</Ref></li>
<li id="L-1-3-3"><span className="rd-rule-id">L.1.3.3</span> 文件头写明出处和 27 项职责立场，用到原版以外的品种或周期须注明 <Ref id="rule:L.1.3.3">research-round · references/template.md</Ref></li>
</ul>

### L.1.4　发起与转写（人造根） [#L-1-4]

用户提供信息源时，按同样的规则转写人造根。

<ul className="rd-rules">
<li id="L-1-4-2"><span className="rd-rule-id">L.1.4.2</span> 人造根信息源缺的参数可补默认值并注明，不弃用也不冒充出处 <Ref id="rule:L.1.4.2">research-round · references/template.md</Ref></li>
</ul>

## L.2　发布为根并出首份报告 [#L-2]

<Steps>

<Step>

发布：根文件原样入账成为候选；相同字节返回已有的候选。

</Step>

<Step>

预检与审查：先做原生预检，再由独立源码审查写结论入账。

</Step>

<Step>

登记：不带父版本和对照，网格只含这个根，锁进账本。

</Step>

<Step>

回放与读取：回放一次并计入试验，审计封存后判经济证据资格。

</Step>

<Step>

修复：任一步暴露故障就改源码另发新根重走，原根的运行留作历史。

</Step>

</Steps>

### L.2.2　首次回放 [#L-2-2]

根的首份报告计入试验次数、没有检验结果，之后可作派生候选的比较对照。

<ul className="rd-rules">
<li id="L-2-2-1"><span className="rd-rule-id">L.2.2.1</span> 新根不带对照登记并回放一次，未登记的回放不能当首份报告 <Ref id="rule:L.2.2.1">research-round · references/template.md</Ref></li>
</ul>

- **第二批多品种／双腿模板的名单与启动时点**　产品允许做现货，但名单未给；<Ref id="L.1.1.2" /> 只写第二批范围：横截面动量、配对、资金费 carry。
- **模板首次回放的范围（全池全开发窗口一次到位，还是先有界先导）**　演练中全池回放工程成本高，多数试验被生命周期、原生身份或容量阻断；<Ref id="L.2.2.1" /> 只写回放一次，范围由用户选。

- **不进文档**　一手出处类型与不收形态的例子：不单列成节；收与不收的例子写进 <Ref id="L.1.3.3" /> 的规则正文。
- **不进文档**　出处列表与参照的因子库：不单列成节；经核实的出处作为一手出处例子放 <Ref id="L.1.3.3" /> 的依据，机制未核实的因子库参照与引擎仓库链接不作出处。
