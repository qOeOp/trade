# Strategy source custody

Develop one complete Nautilus Strategy file in an external working directory,
then publish exact bytes with `research.records.cli strategy publish`. Dolt owns
the source revision and fixed derivation relations. This product directory keeps
only the development contract, not current strategy bodies.

H19a is `r1.broad-two-tier@1`; see [export and execution](../backtest/r1/README.md).
Historical source inventory is [strategy-history.json](../research/strategy-history.json).
Unconverted multi-module variants remain historical closures pending separate
consolidation and paired native acceptance.
