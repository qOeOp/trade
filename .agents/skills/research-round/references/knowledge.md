# Append-only research knowledge and notes

Keep one working knowledge list per market and development window in `/tmp`; each version goes to
Dolt with `evidence add --bundle knowledge-MARKET-WINDOW-vN DIRECTORY`. Read previous versions via
`evidence export`, including closed round tags. Never overwrite the original list or old decisions.
The format is Agent-readable evidence, not a parallel product schema or scheduler.

Retain all complete candidates with exact source identity, development parent and rule change,
registered grid/conditions, comparison control and actual attempted trials/runs. Use `candidate list`
for product custody and `round status` for counts. Separate invalid/incomplete runs from economics.

The list records current recommendation and its reasons over all comparable candidates separately
from next research actions, their priorities and chosen parent. Each update cites supporting
registration, run and ledger commit, and distinguishes facts, explanation and next hypothesis.
Keep historical negative or non-significant findings with applicability. Old excluded classes are
historical decisions, not current hard exclusions; low-priority directions remain reassessable.

Record review cadence/reason and last reviewed attempt; research continues by default. A test's
finite snapshot (for example ten attempts) is not a product stop rule. Optional user execution limits
and interruption retain recovery state. A new market/window needs its own list and exposure record;
old history still counts as search exposure. Switching the user's route waits for user selection.


For each proposed economic hypothesis and subsequent update, trace the three bases in existing
notes: external original/bundle/location and its mechanism/rule/parameter/method scope, fixed-run
local diagnosis, and Agent conjecture/falsifier/unproven transfer. Retain reused-source identity,
query range, reading extent and access limitations. Distinguish publication status and credible
community practice; an internal note, template or method reference is not empirical rule support.
Explain priority using applicability and local information value, never reference count. A no-paper
or inaccessible-source direction remains reassessable. Date later sources as subsequent evidence;
preserve the old registration's original source classification and never retroactively add backing.
