# Selection with an idea or a source

Read when the user's choice of a line comes with an idea, a source or an authorization for a
template.

- **E.4.1.2** An idea the user adds is one ordinary hypothesis in the line: check sources, mark
  each reason external, local or conjecture, write the prediction, precheck, review and register,
  then replay with its control (`research-round` hypothesis.md). It is never exempt from
  registration and never applied by editing source and replaying. A source the user gives is
  transcribed into a new root ([template.md](../../research-round/references/template.md)). An
  authorization to use a template is given once; never ask for it again.
