# Selection with an idea or a source

- An idea the user adds is one ordinary hypothesis in the line: check sources, mark each reason
  external, local or conjecture, write the prediction, precheck, independent source review and
  register, then replay with its control (the research-round skill's hypothesis stage). It is never
  exempt from registration and never applied by editing source and replaying. A source the user
  gives is transcribed into a new root (the research-round skill's template transcription).
