# Compare Viable Alternatives

Compare only materially different paths that remain credible; do not invent competitors to a
dominant repository-native path. Evaluate outcome and consumer fit, existing ownership, added
responsibility, assumptions, reversibility, and verification cost. Recommend the path with the best
decisive tradeoff and state why the strongest runner-up loses.

Treat the caller's requested mechanism as one candidate, never as the baseline that must win.
Explicitly reject it when admitted evidence shows that it broadens responsibility, makes failure less
safe, duplicates an owner, or needs more structure than the consumer outcome. Preserve the outcome
with the smallest credible substitute. Repetition or sunk work cannot change the comparison; new
decision-relevant evidence can.
